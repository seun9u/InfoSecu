### **1. Oracle XE 다운로드 및 서버 업로드**
다운로드는 외부망 자료실을 이용해서 다운로드 한다. cmd 창을 열어서 Downloads 폴더로 이동한 후 다운로드 받은 파일 `oracle-xe-11.2.0-1.0.x86_64.rpm.zip` 을 scp 로 CentOS 7 서버에 linuxadmin 사용자로 업로드한다.

**명령어 설명**
  . **scp**
    - secure copy (remote file copy program) 암호화 전송 원격 복사 프로그램으로 리눅스, 윈도우에 기본으로 설치되어 있다.
    - 사용법
      `usage: scp [-346BCpqrTv] [-c cipher] [-F ssh_config] [-i identity_file] [-J destination] [-l limit] [-o ssh_option] [-P port] [-S program] source ... target`

```cmd
C:\Users\ITSC>cd Downloads
C:\Users\ITSC\Downloads> scp oracle-xe-11.2.0-1.0.x86_64.rpm.zip linuxadmin@192.168.100.10:
```

### **2. CentOS 7 메모리 증설**
CentOS 7 서버의 물리 메모리를 2G 설정하고 Swap 파일을 2G로 설정한다.

**SWAP 파일 정보**
  . SWAP 파일 위치: `/root/swapfile`
  . SWAP 파일 크기: 2G
  . **!!! 중요(팁) !!!**
    - VMware에서 물리적인 메모리를 2G를 설정했는데도 불구하고 용량이 작게 나와서 Oracle XE 11g를 설치할 수 없을 때 SWAP 파일을 생성해서 SWAP 메모리의 용량을 늘려주면 된다.

linuxadmin 사용자의 디렉터리에 `oracle-xe-11.2.0-1.0.x86_64.rpm.zip` 파일을 홈디렉터리로 이동시킨다.
```bash
[root@victim ~]# mv ~linuxadmin/oracle-xe-11.2.0-1.0.x86_64.rpm.zip .

# Before
[root@victim ~]# free
              total        used        free      shared  buff/cache   available
Mem:        1863000      479428      390992        9956      992580     1198092
Swap:       2097148           0     2097148
```

**Swap 을 만드는 방법**
  . 스왑 파티션 생성
    - 설치, 남는 하드디스크로 생성한다.
  . 스왑 파일 생성
    - 일반파일을 스왑 파일로 생성한 후 스왑으로 포맷하고 기존 스왑에 더하면 된다.
  . 스왑 파일 생성 순서
    - 스왑파일 생성(`dd`) > 스왑 파일로 포맷(`mkswap`) > 권한 변경(`chmod`) > 스왑 메모리 추가(`swapon`) > 추가된 스왑 메모리 확인(`free`)
  . `swapon`: 스왑 추가, `swapoff`: 스왑 제거

```bash
[root@victim ~]# dd if=/dev/zero of=swapfile bs=1024 count=2000000
[root@victim ~]# mkswap swapfile
[root@victim ~]# chmod 600 swapfile   <-- -rw-------.
[root@victim ~]# swapon swapfile
[root@victim ~]# ll -h swapfile
-rw-r--r--. 1 root root 2.0G  3월 21 17:40 swapfile

# After
[root@victim ~]# free
              total        used        free      shared  buff/cache   available
Mem:        1863000      467176       78736        2772     1317088     1221172
Swap:       4097144       10760     4086384
```

### **4. Oracle XE 설치**
unzip 명령어로 `oracle-xe-11.2.0-1.0.x86_64.rpm.zip` 파일의 압축을 해제한다.

```bash
[root@victim ~]# unzip oracle-xe-11.2.0-1.0.x86_64.rpm.zip
[root@victim ~]# cd Disk1/
[root@victim Disk1]# rpm -Uvh oracle-xe-11.2.0-1.0.x86_64.rpm
```

설치가 완료되면 root 권한에서 `/etc/init.d/oracle-xe configure` 명령어를 실행해서 설정을 한다.

```bash
[root@victim Disk1]# /etc/init.d/oracle-xe configure

Oracle Database 11g Express Edition Configuration
-------------------------------------------------
: (생략)

Specify the HTTP port that will be used for Oracle Application Express [8080]:9090  <-- 9090입력
Specify a port that will be used for the database listener [1521]:  <-- 오라클 포트 1521번을 기본 포트로 사용하기 위해서 엔터
: (생략)
initial configuration:  <-- DBA(DataBase Administrator) 비밀번호를 설정한다. 여기서는 oracle 로 비밀번호로 설정한다.
Confirm the password:   <-- DBA(DataBase Administrator) 비밀번호를 설정한다. 여기서는 oracle 로 비밀번호로 설정한다.

Do you want Oracle Database 11g Express Edition to be started on boot (y/n) [y]:  <-- 부팅시 활성화하기 위해서 엔터

Starting Oracle Net Listener...Done
Configuring database...Done
Starting Oracle Database 11g Express Edition instance...Done
Installation completed successfully.
```

설치가 완료되면 업로드한 Oracle 관련 파일들은 필요없기 때문에 모두 삭제한다.
```bash
[root@victim Disk1]# cd
[root@victim ~]# rm -rf Disk1/ oracle-xe-11.2.0-1.0.x86_64.rpm.zip
```

### **5. Oracle 사용자 설정**
Oracle 11g XE 를 설치하면 oracle 사용자가 생성되지만 로그인이 안되는 Oracle DBMS만 실행하는 사용자가 시스템에 생성된다.

```bash
[root@victim ~]# grep oracle /etc/{passwd,shadow}
/etc/passwd:oracle:x:1001:1001::/u01/app/oracle:/bin/bash
/etc/shadow:oracle:!!:20533:0:99999:7:::
```

몇 가지 설정을 하기 위해서 oracle 사용자로 변경한다.
```bash
[root@victim ~]# su - oracle
-bash-4.2$ cp /etc/skel/.bash* .
-bash-4.2$ exit
[root@victim ~]# su - oracle
[oracle@victim ~]$
```

`oracle_env.sh` 를 `.bashrc` 마지막에 넣어준다.
```bash
[oracle@victim ~]$ vi .bashrc  
  :  
  :(생략)
source /u01/app/oracle/product/11.2.0/xe/bin/oracle_env.sh
```

로그아웃 하지 않고 `oracle_env.sh`를 실행하기 위해서는 `source` 명령어로 실행한다.
```bash
[oracle@victim ~]$ source .bashrc
```

**sqlplus: Oracle 서버에 접속하는 클라이언트 프로그램**
* 접속 형식: `sqlplus --help`
  . 첫 번째: `sqlplus`
  . 두 번째: `sqlplus 사용자/비밀번호`
  . 세 번째: `sqlplus / as sysdba` (관리자 접속)
* `sys`: 오라클 DB의 관리자 (최고 관리자)
* `system`: 오라클 DB의 관리자

**첫 번째 접속 방법으로 접속한다.**
```bash
[oracle@localhost ~]$ sqlplus

SQL*Plus: Release 11.2.0.2.0 Production on 금 7월 7 15:19:55 2023
Copyright (c) 1982, 2011, Oracle.  All rights reserved.

Enter user-name: system  <-- 사용자 system을 입력한다.
Enter password:   <-- 비밀번호 oracle을 입력한다.
SQL> SHOW USER
USER is "SYSTEM"
SQL> exit
```

**두 번째 접속 방법으로 접속한다.**
```bash
[oracle@localhost ~]$ sqlplus system/oracle
SQL> show user
USER is "SYSTEM"
SQL> select 1+2 from dual;
SQL> exit
```

**세 번째 접속 방법으로 접속한다.**
