## 실습.[LAB] 리눅스 명령어 200개 사용하기 (Part 1)

### 1. 시스템 제어 및 기본 복사/이동
**📍 시스템 종료**
* `sudo shutdown -h now`: 관리자 권한으로 시스템을 지금 당장 셧다운합니다.
  * `-h`: 셧다운 (Halt)
  * `now`: 지금 당장

**📍 파일 및 디렉터리 복사 (`cp`)**
* `cp a b`: 파일 복사
  ```bash
  $ echo Hello > hello.txt
  $ cp hello.txt hello2.txt
  $ cp /etc/hosts hosts      # cp /etc/hosts . 과 동일하게 현재 디렉터리로 복사
  ```
* `cp -r a b`: 디렉터리 복사 (a는 원본이며 반드시 존재해야 함)
  ```bash
  $ mkdir dirA
  $ echo hello > dirA/hello.txt
  $ tree dirA
  $ cp -r dirA dirB
  $ tree dirB
  ```

**📍 파일 및 디렉터리 이동/이름 변경 (`mv`)**
* `mv a b`: 이동 또는 이름 변경 (a는 원본이며 반드시 존재해야 함)
  ```bash
  $ mkdir dirC; mv hello.txt dirC
  $ mkdir dirD; mv hello2.txt dirD
  $ tree dirC dirD
  $ mv dirD/hello2.txt .     # 현재 디렉터리로 이동
  $ mv dirC/hello.txt .
  ```

### 2. 리다이렉션 및 링크 관리
**📍 리다이렉션 (Redirection)**
* **출력 리다이렉션**: `>` (덮어쓰기), `>>` (추가하기)
  * `echo 내용 > file`
  * `echo 내용 >> file`
* **입력 리다이렉션**: `<`, `<<`

**📍 링크 파일 생성 (`ln`)**
* `ln file link`: 하드 링크 생성 (아이노드 번호가 원본 파일과 동일함)
  ```bash
  $ cat << EOF > hello.txt
  > hello
  > hello2
  > EOF
  $ ln hello.txt hello2.txt
  $ ll -i hello.txt hello2.txt  # 아이노드 번호 확인
  ```
* `ln -s file link`: 심볼릭 링크 생성 (아이노드 번호가 원본과 다름, Windows의 바로가기와 유사)
  ```bash
  $ ln -s hello.txt hello3.txt
  $ ll -i
  $ cat hello3.txt
  ```

**📍 파일 삭제 및 설치**
* `unlink`: 인수로 주어진 파일을 삭제합니다. (`rm`과 유사)
  ```bash
  $ unlink hello.txt
  ```
* `install`: 파일 생성, 권한 설정, 디렉터리 생성, 파일 복사 등 다양한 명령을 수행합니다.
  ```bash
  $ install /dev/null file1.txt
  $ install -m 644 /dev/null file2.txt  # 권한 644로 설정
  $ install -d dirA                     # 디렉터리 생성
  $ install /etc/hosts .                # 파일 복사
  ```

### 3. 파일 및 경로 속성 확인
**📍 경로 이름 추출**
* `basename`: 전체 경로에서 파일명만 추출합니다. (주로 셸 스크립트에서 사용)
  ```bash
  $ basename /usr/bin/sort
  $ basename /etc/hosts
  ```
* `dirname`: 전체 경로에서 디렉터리 경로만 추출합니다.
  ```bash
  $ dirname /etc/passwd
  $ dirname /etc/hosts
  ```

**📍 파일 정보 및 종류 확인**
* `file`: 파일의 종류를 확인합니다. 리눅스는 모든 것을 파일로 취급합니다. (정규 파일 `-`, 디렉터리 `d`, 심볼릭 링크 `l`, 블록 장치 `b`, 문자 장치 `c`, 파이프 `p`, 소켓 `s`)
  ```bash
  $ file /etc/hosts        # ASCII text
  $ file /usr/bin/ls       # ELF 64-bit executable
  $ file /etc              # directory
  $ file /usr/bin/sh       # symbolic link
  $ file /dev/tty1         # character special
  $ file /dev/nvme0n1      # block special
  $ file /run/initctl      # fifo (named pipe)
  $ file /run/udev/control # socket
  ```
* `stat`: 파일의 모든 상세 정보(접근 시간, 수정 시간, 크기, 권한 등)를 확인합니다.
  ```bash
  $ stat /etc/hosts
  $ stat /etc
  ```
* `realpath`: 파일이나 디렉터리의 절대 경로를 출력합니다. (`pwd -P`와 동일)
  ```bash
  $ realpath .
  $ realpath file1.txt
  ```
