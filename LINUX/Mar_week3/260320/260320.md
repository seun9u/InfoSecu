### **passwd : 비밀번호 관련 명령어**
* `/etc/shadow`는 `UPLMMWIE(uplmMwie)` 로 되어 있다.
* `U: username`, `P: password`, `L: Lsat password change`, `M: Minimum`, `M: Maximum`, `W: Warning days`, `I: Inactive`, `E: Expire`

* 사용자를 삭제할 때는 1명씩 지운다.
```bash
$ sudo userdel -r user1
$ sudo userdel -r user2
$ sudo userdel -r user3
```

* `U: username` 사용자를 생성할 때 이미 지정되어 있다.
* `P: password` 기본값은 비밀번호가 없다.
* `L: Last password change` 사용자를 생성한 오늘 날짜에 해당하는 일 수 (1970년 1월 1일 부터 일수가 계산)
* `M: Minimum` 기본값은 언제든지 변경할 수 있게 0으로 설정되어 있다.
* `M: Maximum` 기본값은 274년(99999)로 설정되어 있으므로 반드시 변경한다. 변경하지 않으면 취약점으로 처리한다.
* `W: Warning days`: 비밀번호 만료 7일 전 부터 로그인하면 경고가 출력된다.
* `I: Inactive`: 기본값은 없다.
  * 설정이 없는 경우
    - Rocky Linux 9의 기본값은 Inactive가 없다.
    * 비밀번호가 만료되지 않은 경우
      - 정상적으로 로그인이 된다.
    * 비밀번호가 만료된 경우
      - 로그인을 하면 비밀번호를 강제로 재지정한다.
        이전 비밀번호를 물어본 후 비밀번호가 맞으면 강제로 다시 설정한다.
        새로운 비밀번호를 설정하면 비밀번호가 새롭게 설정되고 로그아웃한다.
        사용자는 재설정한 비밀번호로 다시 로그인한다.
        새로운 비밀번호를 설정하지 않으면 로그아웃된다.
        이전 비밀번호를 물어본 후 비밀번호가 맞지 않으면 로그아웃 한다.
  * 설정이 있는 경우
    * 비밀번호가 만료되지 않은 경우
      - 정상적으로 로그인이 된다.
    * 비밀번호가 만료된 경우
      - 유예기간 동안 변경할 수 있게 정상적으로 로그인이 된다.
        - 비밀번호를 변경했을 경우
          새로운 비밀번호를 설정하면 비밀번호가 새롭게 설정되고
          Lsat password change 필드에 변경된 일수가 기록되고 다시 카운트가 된다.
        - 비밀번호를 변경하지 않은 경우
          유예기간이 끝나는 순간 계정이 잠기고 로그인을 못한다.
          이때는 root(슈퍼유저)만이 사용자의 계정을 풀어야 한다.
* `E: Expire`: 기본값은 없다.
  * 사용자 계정 만료 기간이다. 이 기간이 지나면 로그인을 하지 못한다.
    이때는 root(슈퍼유저)만이 사용자의 계정을 풀어야 한다.

```bash
$ sudo grep user1 /etc/shadow
user1:!!:20532:0:99999:7:::

$ sudo passwd user1
$ sudo grep user1 /etc/shadow
user1:$6$rounds=100000$lJUYosF0Hi6Rqrst$aSC7OETlwGl7R8pb ...:20532:0:99999:7:::
```

### **passwd 옵션**
* `-S, --status` : report password status on the named account (root only)
```bash
$ sudo passwd -S user1
user1 PS 2026-03-20 0 99999 7 -1 (Password set, SHA512 crypt.)

$ ssh -l user1 192.168.100.3
user1@192.168.100.3's password:
$ exit
```

* `-l, --lock` : lock the password for the named account (root only)
  - `/etc/shadow` 파일의 비밀번호 필드에 `!!` 를 추가해서 전체 암호를 다르게 설정한다.
* `-u, --unlock` : unlock the password for the named account (root only)
  - `/etc/shadow` 파일의 비밀번호 필드에 `!!` 를 제거한다.
```bash
$ sudo passwd -l user1
$ sudo grep user1 /etc/shadow
user1:!!$6$rounds=100000$lJUYosF0Hi6Rqrst$aSC7OETlwGl7R8pb ... :20532:0:99999:7:::
$ sudo passwd -S user1
user1 LK 2026-03-20 0 99999 7 -1 (Password locked.)

$ ssh -l user1 192.168.100.3
user1@192.168.100.3's password:
Permission denied, please try again.
user1@192.168.100.3's password:

$ sudo passwd -u user1
$ sudo grep user1 /etc/shadow
user1:$6$rounds=100000$lJUYosF0Hi6Rqrst$aSC7OETlwGl7R8pb ... :20532:0:99999:7:::
```

* **비밀번호 강제로 변경하게 설정**

$ ssh -l user1 192.168.100.3

* **비밀번호 최대 사용일 설정하기**
  * 비밀번호 최대 사용일을 30일로 설정한다.
  * `chage` : `-M, --maxdays MAX_DAYS` set maximum number of days before password change to MAX_DAYS
  * `passwd`: `-x, --maximum=DAYS` maximum password lifetime (root only)
```bash
$ sudo passwd -S user1
user1 PS 2026-03-20 0 99999 7 -1 (Password set, SHA512 crypt.)
$ sudo chage -M 30 user1
$ sudo passwd -S user1
user1 PS 2026-03-20 0 30 7 -1 (Password set, SHA512 crypt.)
$ sudo chage -l user1
Last password change                                    : Mar 20, 2026
Password expires                                        : Apr 19, 2026
Password inactive                                       : never
Account expires                                         : never
Minimum number of days between password change          : 0
Maximum number of days between password change          : 30
Number of days of warning before password expires       : 7
```

* **계정 만료 설정하기**
  * `chage` : `-E, --expiredate EXPIRE_DATE` set account expiration date to EXPIRE_DATE
  * `passwd` : `-e, --expire` expire the password for the named account (root only)
```bash
$ sudo chage -E 2026-12-25 user1
$ sudo chage -l user1
Last password change                                    : Mar 20, 2026
Password expires                                        : Apr 19, 2026
Password inactive                                       : never
Account expires                                         : Dec 25, 2026
Minimum number of days between password change          : 0
Maximum number of days between password change          : 30
Number of days of warning before password expires       : 7
```
* `passwd -S` 로는 `Account expires` 를 볼 수 없다.
```bash
$ sudo passwd -S user1
user1 PS 2026-03-20 0 30 7 -1 (Password set, SHA512 crypt.)
```
* 계정 만료 다음날로 설정하고 ssh로 접속하면 계정이 잠긴다.
```bash
$ sudo date 12261800
Sat Dec 26 06:00:00 PM KST 2026

$ ssh -l user1 192.168.100.3
user1@192.168.100.3's password:
Your account has expired; please contact your system administrator.
Connection closed by 192.168.100.3 port 22
```
* 실습이 완료되면 원래의 시간으로 설정한다.
```bash
$ sudo date 03201138
```

* **`--stdin` 옵션**
  * 파이프 통신을 이용해서 비밀번호 변경한다.
  * 이 옵션을 이용하면 셸스크립트에서 비밀번호를 자동화 시키면서 변경할 수 있다.
```bash
$ echo 1234 | sudo passwd --stdin user1

# vi chage_password.sh
#!/bin/sh

a=0000

echo $a | passwd --stdin user1
echo $a | passwd --stdin user2
echo $a | passwd --stdin user3

# chmod 755 chage_password.sh
# ./chage_password.sh
```
