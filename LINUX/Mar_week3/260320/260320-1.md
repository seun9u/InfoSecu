### **faillog : 로그인 실패 기록**
```bash
$ faillog    
```

### **lastlog : 마지막 로그인 확인**
* 로그인의 여부를 확인할 수 있다.
```bash
$ lastlog     
```

### **hostname : 호스트명 확인**
* `FQDN (Fully Qualified Domain Name)`으로 전체 도메인 이름을 출력한다.
  - 호스트 이름부터 도메인 이름까지 전체를 다 적은 이름을 의미한다.
  - `www.naver.com`, `www.daum.net`, `cafe.naver.com`
  - `localhost.localdomain` 은 기본값이고 네트워크 장비에서 Switch, Router 기본 이름으로 보이는 것과 동일하다.
```bash
$ hostname
localhost.localdomain

$ strace hostname
```

### **hostnamectl : 호스트명 설정/확인**
* 호스트명을 확인하거나 변경한다.
  - `localhost.localdomain` 이면 `/etc/hostname` 에 저장되지 않는다.
  - `FQDN`을 설정하면 `/etc/hostname`에 저장된다.
```bash
$ hostnamectl --help
$ sudo hostnamectl hostname command.linuxmaster.net
$ cat /etc/hostname
command.linuxmaster.net
$ hostname
command.linuxmaster.net
$ exit 
  ssh linuxadmin@192.168.100.3
linuxadmin@192.168.100.3's password:
[linuxadmin@command ~]$

$ sudo vi /etc/hosts
127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
192.168.100.3 command.linuxmaster.net command
```
