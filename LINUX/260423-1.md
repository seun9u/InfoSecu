## **실습. [LAB] 쓰레드(Thread) 예제 1: 흐름 분리하기**

**핵심 개념**
* 메인 쓰레드(`main`): 사용자 입력을 기다림 (`scanf`)
* 서브 쓰레드(`thread_function`): 입력을 기다리는 동안 백그라운드에서 1초마다 숫자를 출력

---

### **1. 쓰레드가 없는 경우 (단일 흐름)**
입력을 하지 않으면 프로그램이 다음 줄로 넘어가지 않고 무한정 멈춰있습니다.

```c
// 쓰레드 예제1 (쓰레드 미사용)
#include <stdio.h>

int main() {
    int num;
    printf("정수 입력: ");
    scanf("%d", &num);  // 여기서 입력을 대기하며 멈춤
    printf("입력한 값: %d\n", num);
    return 0;
}
```
```bash
[linuxadmin@localhost ~]$ gcc -o pthread1 pthread1.c
[linuxadmin@localhost ~]$ ./pthread1
정수 입력: 1
입력한 값: 1
```

---

### **2. 쓰레드를 사용하는 경우 (멀티 흐름)**
입력을 기다리는 동안에도 백그라운드에서 숫자가 계속 출력됩니다.

**주요 함수 및 컴파일 옵션**
* `#include <pthread.h>` 헤더 추가 필요
* 컴파일 시 `-lpthread` 라이브러리 링크 옵션 필수
* `pthread_create(&tid, NULL, 함수명, 인수)` : 새 쓰레드를 생성하고 함수를 실행
* `pthread_join(tid, NULL)` : 메인 함수가 먼저 종료되어 서브 쓰레드가 강제 종료되지 않도록 기다림

```c
// pthread1.c (쓰레드 사용)
#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

// 쓰레드가 실행할 함수 선언
void *thread_function(void *arg);

int main() {
    int num;
    pthread_t tid;

    // 1. 새로운 쓰레드 생성 (thread_function 실행)
    if(pthread_create(&tid, NULL, thread_function, NULL) != 0) {
        perror("pthread_create 실패");
        return 1;
    }

    // 2. 메인 쓰레드는 입력을 대기
    printf("정수 입력: ");
    scanf("%d", &num);
    printf("\n입력한 값: %d\n", num);

    // 3. 서브 쓰레드가 끝날 때까지 대기 (필요 시 주석 해제)
    // pthread_join(tid, NULL); 
    return 0;
}

// 4. 서브 쓰레드에서 1초마다 숫자 출력
void *thread_function(void *arg) {
    int i = 1;
    sleep(2); // 메인 쓰레드 출력 메시지와 겹치지 않게 잠시 대기
    
    while(i <= 10) {
        printf("thread_function: %d\n", i++);
        sleep(1);
    }
    return NULL;
}
```

**컴파일 및 실행 결과**
```bash
[linuxadmin@localhost ~]$ gcc -o pthread1 pthread1.c -lpthread
[linuxadmin@localhost ~]$ ./pthread1
정수 입력: 
thread_function: 1
thread_function: 2
thread_function: 3
7  <-- 사용자가 중간에 7 입력
입력한 값: 7
```
*(위 결과를 보면 입력을 멈춰있는 동안에도 쓰레드 함수가 독립적으로 실행되는 것을 볼 수 있습니다.)*
