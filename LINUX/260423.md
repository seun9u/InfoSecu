## **쓰레드 (Thread) 개념 및 C언어 활용**

### **1. 쓰레드(Thread)란?**
* 쓰레드는 프로세스 내부에서 실제로 작업을 수행하는 **실행 흐름(작업 단위)**이다.
* 프로세스가 '실행 중인 프로그램'이라면, 쓰레드는 '그 프로세스 안에서 일을 하는 작업자'라고 볼 수 있다.
* 하나의 프로그램 안에서 키보드 입력 대기, 화면 출력, 네트워크 통신, 파일 저장을 동시에 수행하려면 이런 작업들을 각각 별도의 쓰레드로 나누어 처리해야 한다.
* 이처럼 하나의 프로세스 안에서 여러 개의 작업 흐름을 동시에 실행하는 구조를 **멀티쓰레드(Multi-thread)**라고 한다.

---

### **2. 프로세스와 쓰레드의 차이**

| 구분 | 프로세스 (Process) | 쓰레드 (Thread) |
| :--- | :--- | :--- |
| **정의** | 실행 중인 프로그램 (프로그램 단위) | 프로세스 내부의 실행 단위 (흐름 단위) |
| **메모리** | 독립된 메모리 공간을 가짐 | 같은 프로세스 내에서 **메모리를 공유**함 |
| **자원 공유** | 다른 프로세스와 자원을 쉽게 공유하지 않음 | 다른 쓰레드와 자원 공유가 쉬움 |
| **생성 비용** | 무겁고 느림 | 더 가볍고 빠르게 생성 가능 |

---

### **3. 쓰레드의 핵심 의미 (공유와 독립)**
* **하나의 프로그램 안에서 여러 일을 동시에 할 수 있다.**
  * *메인 쓰레드*: 사용자 입력 대기
  * *작업 쓰레드*: 화면 출력
  * *통신 쓰레드*: 서버와 데이터 송수신
* **같은 프로세스 안에서 자원을 공유한다.**
  * 공유 영역: 코드(Code) 영역, 전역 변수, 정적 변수, 힙(Heap) 메모리, 열린 파일 정보
* **실행 흐름은 따로 가진다. (독립적인 요소)**
  * 독립 영역: 스택(Stack), CPU 레지스터, 프로그램 카운터(PC)
  * 즉, 공유할 것은 공유하고, 실행 자체는 독립적으로 진행된다.

---

### **4. 쓰레드를 사용하는 이유**
* **동시에 여러 작업을 처리하기 위해**
  * 메시지 받기, 메시지 보내기, 화면 갱신 등이 동시에 이루어져야 할 때 각 작업을 분리해서 처리할 수 있다.
* **응답성을 높이기 위해**
  * 메인 쓰레드는 화면을 유지하고, 작업 쓰레드는 시간이 오래 걸리는 계산을 수행하도록 나누면, 무거운 작업을 하는 동안에도 프로그램이 멈추지 않고 즉각 반응할 수 있다.
* **자원 공유가 쉽기 때문에**
  * 프로세스를 여러 개 만들면 서로 메모리가 분리되어 통신(IPC)이 번거롭다. 하지만 쓰레드는 메모리를 공유하므로 데이터 전달이 쉽다.
  * *비유:* 다른 반(프로세스)이면 만나서 얘기하기 어렵지만, 같은 반(쓰레드)의 짝꿍이면 데이터(이야기)를 나누기 쉽다.
* **생성 비용이 적기 때문에**
  * 새 프로세스를 만드는 것보다 새 쓰레드를 만드는 것이 일반적으로 더 가볍다. (생성이 빠르고, 메모리 사용량이 적으며, 컨텍스트 스위칭 전환 비용도 작다.)

---

### **5. 쓰레드의 장단점**

**👍 장점**
* 여러 작업을 동시에 처리할 수 있다.
* 프로그램의 응답성이 좋아진다.
* 같은 프로세스 안에서 데이터 공유가 쉽다.
* 프로세스보다 생성 비용이 적다.

**👎 단점**
* 여러 쓰레드가 같은 데이터를 동시에 접근하면 충돌(동기화 문제)이 발생할 수 있으므로 **동기화 처리**가 반드시 필요하다.
* 디버깅이 어렵다.
* 한 쓰레드에 치명적인 오류가 발생하면 전체 프로세스가 죽는 등 악영향을 줄 수 있다.

### **6. C 언어에서 쓰레드 사용법 (`pthread`)**

* 리눅스/유닉스 계열의 C 언어에서는 보통 **`pthread` (POSIX Threads) 라이브러리**를 사용한다.
* 쓰레드를 생성하여 실행할 때는 **함수 포인터**를 알아야 한다.
  * *함수 포인터란?* 함수가 위치한 메모리 주소를 저장하는 포인터 변수. 함수를 매개변수로 전달하기 위해 사용된다.

**주요 pthread 함수**
* `pthread_create()` : 쓰레드 생성
* `pthread_join()` : 쓰레드 종료 대기 (메인 쓰레드가 서브 쓰레드가 끝날 때까지 기다림)
* `pthread_exit()` : 쓰레드 종료
* `pthread_self()` : 현재 쓰레드 ID 확인

**`pthread_create` 메뉴얼 및 구조**
```c
man pthread_create
#include <pthread.h>

int pthread_create(pthread_t *restrict thread,
                   const pthread_attr_t *restrict attr,
                   void *(*start_routine)(void *),   // <-- 3번째 매개변수: 실행할 함수의 포인터
                   void *restrict arg);              // <-- 4번째 매개변수: 함수에 전달할 인자
```

**`void *` (범용 포인터)의 활용**
쓰레드 함수는 매개변수와 반환형으로 어떤 타입이든 유연하게 받을 수 있도록 `void *` 타입을 사용한다.
```c
// 쓰레드 함수의 기본 형태
void *함수명(void *매개변수)

// 일반 포인터 vs 범용 포인터 비교
int a;             // 일반 변수
int *p = &a;       // 일반 포인터 (int만 가리킴)

char message[10];  
char *p2 = message; // 일반 포인터 (char만 가리킴)

// void 포인터는 데이터 타입에 상관없이 주소를 모두 담을 수 있다.
int b;             
void *p3 = &b;     

char message2[10]; 
void *p4 = message2; 
```
