## **실습. [LAB] 쓰레드 예제 2: 구조체를 이용한 인수 전달**

**핵심 개념**
* `pthread_create()` 함수의 네 번째 인수는 하나(`void *`)만 전달할 수 있습니다.
* 여러 개의 값을 전달하려면 묶음 데이터 타입인 **구조체(struct)** 로 묶어서 구조체의 주소를 전달해야 합니다.
* 스레드 함수 내부에서는 전달받은 `void *arg`를 본래의 구조체 포인터(`ThreadArg *`) 형식으로 **형변환(Casting)** 하여 각 값을 꺼내서 사용합니다.

### **1. 쓰레드 예제 2 (구조체로 내부 값 고정 전달)**

```c
// pthread2.c
// 스레드 예제2 (인수가 있는 경우)
#include <stdio.h>    // printf, scanf, perror
#include <pthread.h>  // pthread_create
#include <unistd.h>   // sleep

// 스레드에 전달할 여러 변수를 묶은 구조체 정의
typedef struct {
    int start;      // 시작 숫자
    int count;      // 끝 숫자
    int sleeptime;  // 대기 시간
} ThreadArg;

void *thread_function(void *arg);

int main() {
    int num;
    pthread_t tid;
    ThreadArg t_arg;

    // 1. 스레드에 전달할 값 설정
    t_arg.start = 10;
    t_arg.count = 30;
    t_arg.sleeptime = 5;

    // 2. 구조체의 주소(&t_arg)를 스레드 함수의 네 번째 인수로 전달
    if(pthread_create(&tid, NULL, thread_function, &t_arg) != 0) {
        perror("pthread_create");
        return 1;
    }

    printf("정수 입력: ");
    scanf("%d", &num);
    printf("입력한 값: %d\n", num);

    // 스레드 종료 대기 (필요 시 주석 해제)
    // pthread_join(tid, NULL);
    return 0;
}

void *thread_function(void *arg) {
    // 3. 전달받은 범용 포인터(void *)를 원래 구조체 포인터로 형변환
    ThreadArg *data = (ThreadArg *)arg;

    // 4. 구조체 멤버에서 값을 꺼내어 변수에 저장
    int i = data->start;
    int count = data->count;
    int sleeptime = data->sleeptime;

    sleep(sleeptime);

    while(i <= count) {
        printf("thread_function: %d\n", i++);
        sleep(1);
    }
    return NULL;
}
```

**컴파일 및 실행 결과**
```bash
[linuxadmin@localhost ~]$ gcc -o pthread2 pthread2.c -lpthread
[linuxadmin@localhost ~]$ ./pthread2
정수 입력: 
thread_function: 10
thread_function: 11
thread_function: 12
100  <-- 사용자가 중간에 100 입력
입력한 값: 100
```

## **실습. [LAB] 쓰레드 예제 3: `main` 함수의 실행 인수로 전달받기**

**핵심 개념**
* 예제 2에서 고정으로 넣었던 값을 프로그램 실행 시 커맨드 라인 인자(`argc`, `argv`)로 받아와 구조체에 넣고 스레드에 전달합니다.
* 사용자가 값을 잘못 입력했을 때의 예외 처리(인수 개수 확인, 대소 비교)가 추가되었습니다.

### **2. 쓰레드 예제 3 (`argv` 활용)**

```c
// pthread3.c
// 스레드 예제3 (인수가 있고 main() 에서 인수로 받는 경우)
#include <stdio.h>    // printf, scanf, perror
#include <pthread.h>  // pthread_create
#include <unistd.h>   // sleep
#include <stdlib.h>   // atoi (문자열을 정수로 변환)

typedef struct {
    int start;      // 시작 숫자
    int count;      // 끝 숫자
    int sleeptime;  // 대기 시간
} ThreadArg;

void *thread_function(void *arg);

int main(int argc, char **argv) {
    int num, start, count, sleeptime;
    pthread_t tid;
    ThreadArg t_arg;

    // 1. 실행 인수 개수 확인 (명령어 포함 총 4개여야 함)
    if(argc != 4) {
        fprintf(stderr, "Usage %s start count sleeptime\n"
                        "e.g.) %s 10 30 5 \n", argv[0], argv[0]);
        return 1;
    }

    // 2. 문자열 인수를 정수로 변환
    start = atoi(argv[1]);
    count = atoi(argv[2]);
    sleeptime = atoi(argv[3]);

    // 3. 예외 처리: 시작값이 끝값보다 큰 경우
    if(start > count) {
        fprintf(stderr, "start 가 count 보다 작아야 합니다.\n");
        return 2;
    }

    // 4. 스레드에 전달할 구조체 변수 설정
    t_arg.start = start;
    t_arg.count = count;
    t_arg.sleeptime = sleeptime;

    // 5. 스레드 생성 및 구조체 주소 전달
    if(pthread_create(&tid, NULL, thread_function, &t_arg) != 0) {
        perror("pthread_create");
        return 1;
    }

    printf("정수 입력: ");
    scanf("%d", &num);
    printf("입력한 값: %d\n", num);

    // 스레드 종료 대기
    // pthread_join(tid, NULL);
    return 0;
}

void *thread_function(void *arg) {
    // 6. 범용 포인터 형변환 및 값 추출
    ThreadArg *data = (ThreadArg *)arg;

    int i = data->start;
    int count = data->count;
    int sleeptime = data->sleeptime;

    sleep(sleeptime);

    while(i <= count) {
        printf("thread_function: %d\n", i++);
        sleep(1);
    }
    return NULL;
}
```
