## **실습. [LAB] 리눅스 셸(Shell) 환경 및 History 기능 다루기**

### **1. 프롬프트(PS1) 변수 설정**
환경 변수 `PS1`을 조작하여 터미널 프롬프트의 모양을 변경할 수 있습니다.

```bash
[root@command ~]# PS1="\t ==> "
14:38:02 ==>
14:38:02 ==> PS1="[\u@H \W]\\$ "
[root@H ~]# PS1="[\u@\H \W]\\$ "
[root@command.linuxmaster.net ~]#
[root@command.linuxmaster.net ~]#
[root@command.linuxmaster.net ~]#
[root@command.linuxmaster.net ~]# cd /usr/local/
[root@command.linuxmaster.net local]# PS1="[\u@\H \w]\\$ "
[root@command.linuxmaster.net /usr/local]# PS1="[\u@\h \W]\\$ "          
```

### **2. 사용 가능한 셸(Shell) 확인 및 tcsh 설치**

```bash
# 현재 시스템에서 사용 가능한 셸 확인
[root@command ~]# ll /etc/shells
-rw-r--r--. 1 root root 44  6월 23  2020 /etc/shells
[root@command ~]# cat /etc/shells
/bin/sh
/bin/bash
/usr/bin/sh
/usr/bin/bash

# tcsh 패키지 설치
[root@command ~]# dnf -y install tcsh > /dev/null

# 설치된 tcsh 및 심볼릭 링크 확인
[root@command ~]# ll /bin/csh
lrwxrwxrwx. 1 root root 4  5월 16  2022 /bin/csh -> tcsh
[root@command ~]# ll /bin/tcsh
-rwxr-xr-x. 1 root root 488080  5월 16  2022 /bin/tcsh

# 설치 후 다시 셸 목록 확인
[root@command ~]# cat /etc/shells
/bin/sh
/bin/bash
/usr/bin/sh
/usr/bin/bash
/bin/csh
/bin/tcsh
/usr/bin/csh
/usr/bin/tcsh
```

### **3. bash vs tcsh 변수 설정 차이**

**1) bash**
* bash 실행이 되는 것은 인증에 성공해서 시스템에 로그인을 하면 `/bin/bash`가 실행된다.
* bash 셸에서는 변수에 값을 저장할 때 **`변수명=값`** 을 사용한다.

```bash
# grep ^root /etc/passwd
root:x:0:0:root:/root:/bin/bash

# a=1
# echo $a
1
```

**2) tcsh**
* tcshell로 변경하려면 `tcsh` 패키지를 설치한 후 `tcsh`를 실행하면 된다.
* C셸(tcsh)에서는 변수에 값을 저장할 때 **`set 변수명 = 값`** 을 사용한다.

```bash
# dnf -y install tcsh
# echo $SHLVL
1

# tcsh
# echo $SHLVL
2

# a=1
a=1: Command not found.

# set a = 1
# echo $a
1
# set b=1
# echo $b
1
```

### **4. bash의 히스토리(history) 기능**

**개요**
* bash 셸에 있는 기능으로 사용자가 이전에 입력한 명령어를 저장/조회/실행할 수 있는 기능이다.
* 오리지날 바이너리 파일: `/usr/bin/bash`
* 심볼릭 링크 파일(윈도우의 바로가기): `/bin/bash`, `/bin/sh`, `/usr/bin/sh`

**1) 히스토리 저장 파일 (`~/.bash_history`)**
* `~` 은 사용자를 말한다. (`~`: 자신의 홈디렉터리, `~사용자`: 사용자 홈디렉터리)

```bash
# ls ~/.bash_history
/root/.bash_history
# ls ~linuxadmin/.bash_history
/home/linuxadmin/.bash_history

# cat .bash_history
# wc -l .bash_history
156 .bash_history
```

**2) 히스토리 관련 환경 변수**

* **`HISTSIZE`**: 현재 세션에서 기억할 히스토리 개수 변수 (메모리)
  * 기본값은 1000개로 설정되어 있고 얼마든지 변경이 가능하다.
```bash
# echo $HISTSIZE
1000
```

* **`HISTFILE`**: 히스토리를 저장하는 파일 경로가 지정된 변수
```bash
# echo $HISTFILE
/root/.bash_history
```

* **history 명령어 동작 방식**: `HISTSIZE` (메모리) + `~/.bash_history` (파일)
```bash
# > ~/.bash_history
# HISTSIZE=0
# history
# exit
$ su -

# history
    1  history    
# 1
# 2
# 3
# history
    1  history
    2  1
    3  2
    4  3
    5  history
# exit
$ su -
```

**💡 중요: 해킹 공격 시 히스토리 파일 조작**
이전에 사용했던 명령어는 로그아웃을 하면 환경변수 `HISTFILE`에 설정된 파일에 저장된다.
공격을 당하게 되면 공격자는 환경변수 `HISTFILE`의 값을 `/dev/null`로 조작하여 기록을 남기지 않는다.
```bash
# cat .bash_history
history
1
2
3
history
exit

# echo $HISTFILE
/root/.bash_history
# HISTFILE=/dev/null
# HISTFILE=~/.bash_history

# history
    1  history   <-- 여기부터 6 exit 까지 이전에 로그인한 세션에서 실행한 명령어
    2  1
    3  2
    4  3
    5  history
    6  exit
    7  cat .bash_history  <-- 여기부터 끝까지 현재 로그인한 세션에서 실행한 명령어
    8  echo $HISTFILE
    9  HISTFILE=/dev/null
   10  HISTFILE=~/.bash_history
   11  history
```

**3) 히스토리 단축키 및 실행 기능**

* **방향키 (위, 아래)**: 이전, 이후 명령어를 사용할 수 있는 키이다.
  * `↑` : 이전 명령
  * `↓` : 다음 명령
* **`history`**: 지금까지 사용한 명령어를 출력한다. (`[현재 세션 메모리] + [~/.bash_history]`)
  * 출력 시 나오는 번호가 히스토리 번호이며, 그 옆에 명령어가 나온다.
* **`!!`**: 바로 이전 명령어를 재실행한다.
* **`!번호`**: 히스토리 번호에 해당하는 명령어를 실행한다.
* **`!문자열`**: 히스토리에 기록된 가장 최근 명령어 중 해당 문자열로 시작하는 명령어를 찾아 실행한다.

```bash
# id
uid=0(root) gid=0(root) groups=0(root) context=unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023
# !!
id
uid=0(root) gid=0(root) groups=0(root) context=unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023

# id
# pwd
# df
# history | tail -n 5
  187  history
  188  id
  189  pwd
  190  df
  191   history | tail -n 5
# !188
id
uid=0(root) gid=0(root) groups=0(root) context=unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023

# history | tail
  189  pwd
  190  df
  191   history | tail -n 5
  192  id
  193  pwd
  194  cat /etc/passwd
  195  pwd
  196  history | tail
  197  cat /etc/passwd
  198  history | tail

# !p
pwd
/root
# !w  <-- pwd의 w가 아니다.
-bash: !w: event not found
```

**4) 환경 변수 시간 출력 (`HISTTIMEFORMAT`)**
* 히스토리 출력 시 시간 포맷을 설정하는 변수. (초기값은 아무것도 없다.)
* `export`로 설정하면 현재 로그인한 세션에서 일시적으로 변경되는 것이고 로그아웃을 하면 사라진다.

```bash
# echo $HISTTIMEFORMAT
   <-- 처음에는 시간 설정이 없다.
#    

# export HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S "
# history
   12  2026-04-13 16:28:02 ls -a
   13  2026-04-13 16:29:47 export HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S "
   14  2026-04-13 16:29:47 history
```
