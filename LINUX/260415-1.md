## **리눅스 디렉터리 구조 및 /opt 실습**

### **1. 디렉터리 구조**

**`/bin`**
* `/bin` -> `/usr/bin` 디렉터리의 심볼릭 링크 파일

**`/boot`**
* `System.map-5.14.0-611.5.1.el9_7.x86_64`
  - 해당 커널 버전의 커널 심볼 테이블로 커널 내부 함수/변수 주소 정보가 들어 있다.
  - 디버깅, 커널 분석, 문제 추적 시 사용된다.
* `config-5.14.0-611.5.1.el9_7.x86_64`
  - 해당 커널이 어떤 옵션으로 빌드되었는지 저장한 설정 파일이다.
  - 특정 드라이버가 포함되었는지, 모듈 방식인지 등이 기록된다.
* `efi/`
  - UEFI 부팅 환경에서 사용하는 관련 파일들이 들어 있는 디렉터리이다.
* `grub2/`
  - GRUB2 부트로더 관련 파일과 설정이 들어 있는 디렉터리이다.
  - 부팅 메뉴, 기본 커널 선택, 커널 옵션 등이 여기와 연관되어 있다.
* `initramfs-0-rescue-f0944cdf13ba4837941aac35d14789be.img`
  - 복구용(rescue) 커널 이미지이다.
  - rescue용 초기 RAM 디스크 이미지이다.
  - 일반 커널 부팅이 안 될 때 복구용(rescue) 커널과 함께 사용된다.
* `initramfs-5.14.0-611.5.1.el9_7.x86_64.img`
  - 현재 커널 버전에 맞는 일반 initramfs 이미지이다.
  - 부팅 초기에 필요한 드라이버, 모듈, 루트 파일시스템 마운트 관련 내용이 들어 있다.
* `initramfs-5.14.0-611.5.1.el9_7.x86_64kdump.img`
* `loader/`
* `symvers-5.14.0-611.5.1.el9_7.x86_64.gz`
* `vmlinuz-0-rescue-f0944cdf13ba4837941aac35d14789be`
* `vmlinuz-5.14.0-611.5.1.el9_7.x86_64` 
  - 현재 커널 버전의 실제 리눅스 커널 이미지이다.
  - 부팅 시 가장 핵심이 되는 파일이다.

## **실습. [LAB] /opt 디렉터리**

### **1. XAMPP**
* 웹 서버 개발에 필요한 주요 소프트웨어를 한 번에 설치하여 사용할 수 있도록 묶어 놓은 통합 패키지
* 웹 개발 학습, 실습, 테스트용 로컬 서버 환경을 빠르게 구축할 때 사용한다.

**XAMPP 이름의 의미**
* **X**: Cross Platform, 여러 운영체제에서 사용 가능
* **A**: Apache 웹서버, 웹 서버 애플리케이션
* **M**: MariaDB / MySQL, 데이터베이스 서버
* **P**: PHP, 서버 사이드 스크립트 언어
* **P**: Perl, 스크립트 언어

**XAMPP의 주요 구성 요소**
* **Apache**: 웹 브라우저의 요청을 받아 HTML, PHP 등의 웹 페이지를 제공하는 웹 서버 프로그램
* **MySQL / MariaDB**: 웹 애플리케이션의 데이터를 저장하는 DBMS
* **PHP**: 동적 웹 페이지를 만드는 데 사용하는 서버 측 프로그래밍 언어
* **Perl**: 다양한 스크립트 작업에 사용할 수 있는 언어

### **2. 패키지(package) 란**
* 소프트웨어를 설치, 관리, 삭제, 업데이트하기 쉽도록 프로그램 파일, 설정 파일, 라이브러리, 문서, 메타정보 등을 하나로 묶어 놓은 배포 단위를 말한다.
* 이 꾸러미 파일은 확장자가 `파일명.rpm` 으로 되어 있다.
  - rpm (Redhat Package Manager) 의 약자이다.
  - 레드햇 계열 리눅스에서는 `~~~.rpm` 확장자를 가진 파일이 패키지 파일이다.

**패키지 정보**
* **RPM 패키지**: Red Hat 계열에서 사용하는 패키지 형식
* **DEB 패키지**: Debian/Ubuntu 계열에서 사용하는 패키지 형식

**패키지 관리자**: 패키지를 설치/삭제/업데이트하는 도구
* **Rocky Linux**: `yum`, `dnf`, `rpm`
* **Ubuntu**: `apt-get`, `apt`, `dpkg`

### **3. dnf 패키지 설치 프로세스**

`dnf`는 패키지를 설치할 때 저장소에서 `.rpm` 파일을 다운로드 받아서 `/var/cache/dnf/` 아래에 임시로 저장한다. 그리고 모든 패키지가 다운로드되면 설치를 수행한다.
설치가 정상적으로 완료되면 기본 설정에서는 캐시를 삭제하지만 `keepcache` 옵션에 따라 유지할 수도 있다.
* `keepcache=True`

**dnf 패키지 설치 시 순서**
1. `.rpm` 파일 다운로드 받아서 `/var/cache/dnf/` 디렉터리에 저장한다.
   - rpm 파일을 확인하려면 아래 명령어를 사용한다.
     ```bash
     find /var/cache/dnf/ -name "*.rpm"
     ```
2. 다운로드가 완료되면 패키지를 설치한다.
3. 설치가 완료되면 다운로드 받은 패키지를 삭제한다.
   - `keepcache=True` 옵션이 있으면 삭제를 하지 않는다.
   - 강제로 삭제하려면 `dnf clean packages`를 실행한다.
