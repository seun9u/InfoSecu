## **실습. [LAB] vi / vim 에디터 고급 활용법**

### **1. vi에서 바로 반응하지 않는 키 (조합형 키)**
* **숫자, `z`, `g`, `d`, `c`, `y`** 등은 단독으로 누르면 바로 반응하지 않고 다른 키와 조합해야 동작합니다.
  * 예시: `3yy` (3줄 복사) -> `p` (붙여넣기) -> `y3y` (오타 주의, 일반적으로 `3yy` 사용) -> `p` (붙여넣기)

### **2. 붙여넣기 (`p`, `P`) 동작 방식**
* **엔터(줄바꿈)가 있는 경우 (`yy` 등)**: 커서가 있는 위치에서 위(`P`), 아래(`p`)로 새로운 줄에 붙여넣기가 된다.
* **엔터(줄바꿈)가 없는 경우 (`yw`, `yW` 등)**: 커서가 있는 위치에서 왼쪽(`P`), 오른쪽(`p`)으로 같은 줄에 붙여넣기가 된다.

### **3. 시스템 및 사용자 정의 레지스터 (Registers) 사용하기**

**자동 저장 레지스터**
* **`"1` ~ `"9` (이전 삭제 내역)**: 최근에 삭제(`dd`, `cc` 등)한 내용이 순차적으로 저장된다. (`"1`이 가장 최근)
* **`"-` (Small delete register)**: 한 줄보다 작은 범위를 삭제하거나 변경했을 때 그 내용이 저장된다. (예: `dw`, `cw`, `x`, `X`)

**사용자 정의 레지스터 (`"a` ~ `"z`)**
* **`"a` ~ `"z`**: 사용자가 직접 지정하여 복사/삭제한 내용을 담아둘 수 있다. (단어 형태는 불가, 한 글자만 사용)
* **`"A` ~ `"Z`**: 대문자를 사용하면 기존 레지스터 내용에 **추가(Append)**가 된다. (`a` <--> `A` 매칭)
  * `"a` 레지스터가 없으면 생성되고, 있으면 추가된다.
  * `"By`: `"b` 레지스터가 없으면 생성되고, 있으면 추가된다.

**[사용자 정의 레지스터 실습]**
```c
$ vi file.c

// file.c
// :w > gg > V > G > "ay > :reg
// :n file2.c > "aP
#include <stdio.h>

// 블럭을 잡고 > "ay > :reg
int main(){
    return 0;
}
// 블럭을 잡고 > "Ay > :reg
```

### **4. 들여쓰기 (`>>`, `<<`)**
* 블록을 잡거나 특정 줄에서 `>>` (들여쓰기), `<<` (내어쓰기)를 할 수 있다.
* 이는 vi 설정 옵션에 영향을 받는다. (예: `set sw=4`, `set expandtab` 등)

### **5. 정규표현식을 활용한 검색 패턴 예시**
* `/TERM` : `TERM` 문자열을 검색
* `/^TERM` : `TERM`으로 시작하는 문자열을 검색
* `/TERM$` : `TERM`으로 끝나는 문자열을 검색
* `/[0-9]` : 숫자 1개가 포함된 부분을 검색
* `/[a-z]` : 영문 소문자 1개 이상을 검색
* `/[A-Z]` : 영문 대문자 1개 이상을 검색
* `/^$` : 빈 줄 검색

### **6. ex 모드(`:`) 범위 지정 및 명령어**

**범위 지정 형식**
* **`:%`** : 문서 전체
* **`:시작,끝`** : 절대 위치 지정 (예: `:3,9` -> 3번 라인부터 9번 라인까지)
* **`:+`, `:-`** : 현재 커서 기준 상대 위치 지정
* **`.` (또는 생략)** : 커서가 있는 현재 라인
  * *참고: vim에서 범위를 설정하면 자동으로 하이라이팅이 된다.*

**자주 사용하는 범위 지정 명령어**
* **`d` (삭제, Delete)**
  * `:1,3d` : 1번 라인 ~ 3번 라인까지 삭제한다.
* **`y` (복사, Yank)**
  * `:1,3y` : 1번 라인 ~ 3번 라인까지 복사한다.
* **`p` (출력, Print)**
  * `:1,3p` : 1번 라인 ~ 3번 라인까지 화면에 출력한다.
* **`s` (치환, Substitute)**
  * `:1,3s/old/new/g` : 1번 라인 ~ 3번 라인까지 `old`를 `new`로 교체한다.
* **`co`, `to` (복사, Copy/To)**
  * `:1,5co9` : 1번 라인 ~ 5번 라인까지의 내용을 9번 라인 밑(10번 라인)으로 복사한다.
* **`m` (이동, Move)**
  * `:11,13m5` : 11번 라인 ~ 13번 라인까지의 내용을 5번 라인 밑으로 이동시킨다.
* **`w` (파일 저장, Write)**
  * `:1,3w test.txt` : 1번 라인 ~ 3번 라인까지의 내용만 `test.txt` 파일로 저장한다.

**상대 위치(`+`, `-`) 지정 실습**
* `:+3` (Enter) : 현재 줄에서 아래로 3줄 떨어진 줄 위치로 커서를 이동한다.
* `:+3d` : 현재 줄에서 아래로 3줄 떨어진 줄 라인을 삭제한다.
* `:.,+3d` : 현재 줄(`.`)부터 아래로 3줄(`+3`)까지 범위를 삭제(`d`)한다.

### **7. 치환(`s`) 옵션 (`g`, `c`)**
* **`g` (Global) 옵션**: 한 행에서 찾을 문자열이 2개 이상이 있어도 모두 변경한다. `g` 옵션이 없으면 각 줄의 첫 번째 문자열만 변경된다.
* **`c` (Confirm) 옵션**: 문자열을 치환할 때마다 확인 메시지를 출력하여 실제로 변경할지 여부를 하나하나 물어본다.
