## 실습.[LAB] 명령어 200개 사용하기

**📍 명령어 종류**
* **alias 명령어**: 사용자가 지정한 별칭 명령어
* **내부 명령어**: 쉘(Shell) 자체에 내장된 명령어
* **외부 명령어**: 별도의 실행 파일로 존재하는 명령어

---

### 1. 실습 네트워크 및 기본 접속 환경

**📍 IP 및 서브넷 정보**
* **네트워크**: `192.168.100.0/24` (Subnet Mask: 255.255.255.0 / `11111111.11111111.11111111.00000000`)
* **네트워크 주소**: 192.168.100.0
* **브로드캐스트 주소**: 192.168.100.255
* **가용 IP 주소**: 192.168.100.1 ~ 192.168.100.254
* **Host OS IP**: 192.168.100.1

**📍 기본 접속 및 제어 명령어**
* `ssh -l linuxadmin 192.168.100.3`: 192.168.100.3 서버로 원격 접속하기
* `nmtui`: 네트워크 설정(Network Manager Text User Interface)
* `reboot`: 시스템 재부팅

---

### 2. 기본 이동 및 목록 확인 명령어

**📍 화면 제어 및 환경 변수**
* `clear`: 화면 지우기 (단축키: `Ctrl + L`)
* `pwd`: 현재 작업 중인 디렉터리 위치 확인
* `echo $LANG`: 언어셋 환경변수에 설정된 값 보기
* `LANG=en_US.UTF-8`: LANG 환경변수를 영문 값으로 변경

**📍 디렉터리 목록 보기 (`ls`)**
* `ls`: 파일 목록 보기
* `ls -l`: 파일 자세히 보기
* `ls -a`: 숨김 파일까지 포함해서 보기
* `ls -alh`: 용량 단위(KB, MB 등) 보기 (숨김 파일 포함)
* `ls -alt`: 시간순으로 보기 (숨김 파일 포함)
* `ls /`: 최상위 디렉터리(`/`) 목록 보기

**📍 경로 이동 (`cd`)**
* `cd`: 기본 디렉터리로 이동
* `cd /etc`: `/etc` 디렉터리로 이동
* `cd ..`: 상위 디렉터리로 이동
* `cd /home`: `/home` 디렉터리로 이동
* `cd /`: 최상위 루트 디렉터리로 이동
* `cd ~`: 사용자의 홈 디렉터리로 이동
* `cd -`: 바로 이전에 있던 디렉터리로 이동

**📍 트리 구조 보기 (`tree`)**
`tree` 명령어는 별도의 패키지 설치가 필요합니다.
```bash
# linuxadmin 사용자를 관리자 그룹(wheel)에 포함
usermod -G wheel linuxadmin

# 관리자 권한으로 tree 패키지 설치
$ sudo dnf -y install tree

# tree 명령어 사용 예시
$tree /boot   # /boot 디렉터리를 tree 형식으로 출력$ tree /etc    # /etc 디렉터리를 tree 형식으로 출력
```

**📍 기록 및 별칭 관리**
* `history`: 사용했던 명령어 기록 보기
* `alias`: 별칭 명령어 보기 및 설정 (C언어의 `#define`과 유사한 개념)
  * 예: `$ alias LINUX=ls` (이후 `LINUX`를 입력하면 `ls`가 실행됨)
* `unalias`: 설정된 별칭 제거
  * 예: `$ unalias LINUX`

**📍 출력 및 환경 변수 관리**
* `echo`: 문자열 출력 (예: `$ echo Hello`, `$ echo $LANG`)
* `printf`: 형식 지정 출력 (예: `$ printf "Hello\n"`)
* `env` / `printenv`: 전체 환경변수 출력 및 확인
* `export`: 환경변수 설정 및 전역(Global) 적용
  ```bash
  $ a=1
  $ export a
  $ echo $a   # 1 출력
  $ bash      # 하위 쉘(subshell) 진입
  $ echo $a   # export 했으므로 하위 쉘에서도 1 출력
  $ exit      # 하위 쉘 종료
  $ exit      # 원래 쉘 종료
  ```

### 3. 파일 및 디렉터리 생성/삭제

**📍 생성 명령어**
* `touch`: 0 byte의 빈 파일 만들기 (일반 파일은 권한 맨 앞자리가 `-`로 시작)
  ```bash
  $ touch file1.txt file2.txt file3.txt
  $ ls -l
  ```
* `mkdir`: 디렉터리 만들기 (디렉터리는 권한 맨 앞자리가 `d`로 시작)
  ```bash
  $ mkdir dir1 dir2 dir3
  $ ls -l
  ```
* `mkdir -p`: 존재하지 않는 하위 경로까지 한 번에 만들기
  ```bash
  $ mkdir -p dir4/dir5
  $ tree -F .
  ```

**📍 삭제 명령어**
* `rmdir`: 빈 디렉터리 삭제 (디렉터리 안에 파일이 있으면 삭제 불가)
  ```bash
  $ rmdir dir1 dir2 dir3
  # dir4 안에 dir5가 있다면 rmdir dir4는 에러 발생
  ```
* `rm`: 파일 삭제 (복구가 어려우므로 주의해서 사용)
  ```bash
  $ rm file1.txt
  $ rm file2.txt file3.txt
  ```
* `rm -r`: 디렉터리 및 하위 파일까지 모두 삭제 (Recursive)
  ```bash
  $ rm -r dir4
  ```
* `rm -i`: 삭제 전 사용자에게 확인(Prompt) 받기
  ```bash
  $ touch hello.txt
  $ rm -i hello.txt
  ```
* `rm -f`: 묻지 않고 강제로 바로 삭제 (Force)
  ```bash
  $ touch file1.txt file2.txt file3.txt
  $ alias rm='rm -i'    # rm 명령어를 기본적으로 물어보도록 변경
  $ rm file1.txt        # 삭제할지 물어봄
  $ rm -f file2.txt     # 묻지 않고 바로 삭제됨
  ```
* `rm -rf`: 디렉터리와 하위 내용물 전체를 묻지 않고 강제 재귀 삭제 (가장 주의해야 할 명령어)
  ```bash
  $ mkdir rm-rf
  $ touch rm-rf/file1.txt
  $ tree rm-rf/
  $ rm -r rm-rf       # 삭제 확인 과정을 거칠 수 있음
  $ rm -rf rm-rf      # 확인 없이 디렉터리 통째로 완전 삭제
  ```
