## **실습. [LAB]> Oracle JDBC 드라이버 설치하기**

```text
jsp 코드 ---- [JDBC 드라이버] -------> [Oracle, MS SQLServer, MySQL, MariaDB, ...]
                   |
                   +-- DBMS 업체에서 제공한다.
                       여기서는 오라클11gXE를 사용하므로 이미 JDBC 드라이버를 가지고 있다.
```

### **JDBC (Java Database Connectivity)**
  . JDBC의 약자로 자바 프로그램에서 데이터베이스에 공통된 방식으로 접근할 수 있도록 API를 제공하는 클래스의 집합을 말한다.
  . 이미 DB연결에 관련된 클래스파일을 모아놓은 것이다.
  . 다시 말해서 JDBC를 설치해야 JAVA or JSP에서 DBMS로 연결이 가능하다는 것이다.
  . 이 파일을 확인하기 위해서는 `jar -tvf [디렉터리 경로]/ojdbc6.jar` 로 확인할 수 있다.
  . Tomcat + JAVA + Oracle XE 설치 후 JDBC 드라이버를 톰캣 디렉터리에 복사해야 JSP에서 Oracle 로 접근할 수 있다. 만약 복사하지 않는다면 DB에 접속 할 수가 없으므로 DB 접속 에러가 발생한다.

### **JDBC 드라이버 위치**
  . **Oracle JDBC 드라이버**
    - `/u01/app/oracle/product/11.2.0/xe/jdbc/lib/ojdbc6.jar`
  . **MariaDB JDBC 드라이버**
    - 나중에 생성
  . **Tomcat JDBC 드라이버 위치**
    - `~tomcat/lib/`
  . **Java JDBC 드라이버 위치**
    - 형식: `/usr/lib/jvm/<java version>/jre/lib/ext/`
    - `/usr/lib/jvm/java-1.8.0-openjdk-1.8.0.262.b10-1.el7.x86_64/jre/lib/ext/`

**SELinux(보안 강화 리눅스) 설정 변경**

[root@victim ROOT]# getenforce
Enforcing
[root@victim ROOT]# setenforce 0
