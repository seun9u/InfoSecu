```java
/* * 파일명: JdbcTest.java 
 * 프로그램 설명: Oracle JDBC 연결 테스트 
 * * JDBC(Java Database Connectivity)란? 
 * JAVA와 JSP 프로그램에서 DBMS 작업을 처리하는 자바 표준 인터페이스이다. 
 * SQL문을 실행하기 위한 자바 라이브러리로 JDBC API를 사용할 경우 DBMS의 종류와 상관없이  
 * SQL문을 실행할 수 있다. 
 * * JDBC 사용 순서 
 * 1. java.sql.* 패키지들을 임포트한다. 
 * 2. Oracle/MariaDB JDBC 드라이버를 로딩한다. 
 * 3. DBMS 접속을 위한 Connection 객체를 생성한다. 
 * 4. SQL문을 실행하기 위한 객체를 생성한다. 
 * - Statement/PreparedStatement/CallableStatement 
 * - Statement: String 형태의 완성된 SQL 쿼리를 실행할 때 사용한다. 
 * - PreparedStatement: Statement와 비슷하나 파라미터 처리가 가능하고 SQL String 내  
 * ?와 개별 파라미터를 바인딩한다. 
 * - CallableStatement: PreparedStatement의 확장으로 DBMS에서 프로시저를 실행할 때 사용한다.  
 * 5. SQL문을 실행한다. 
 * 6. SQL문의 결과 값을 사용한다.  
 * - ResultSet 
 * 7. 사용된 객체를 종료한다.  
 * - ResultSet, Statement/PreparedStatement/CallableStatement, Connection 
 */

// 1. java.sql.* 패키지들을 임포트한다.
import java.sql.*;
//import java.sql.Connection;
//import java.sql.DriverManager;
//import java.sql.PreparedStatement;
//import java.sql.ResultSet;
//import java.sql.SQLException;

public class JdbcTest {
    public static void main(String[] args) {        
        Connection con = null;        
        PreparedStatement pstmt = null;           
        ResultSet rs = null;            
        
        try {        	
            // 2. MariaDB JDBC 드라이버를 로딩한다.      	            
            // Class.forName("org.mariadb.jdbc.Driver");            
            
            // 2. Oracle JDBC 드라이버를 로딩한다.      	            
            Class.forName("oracle.jdbc.driver.OracleDriver");            
            // System.out.println("mariaDB Driver를 로딩했습니다.");                    	
            
            // 3. DBMS 접속을 위한 Connection 객체를 생성한다.            
            // String dbURL = "jdbc:mariadb://localhost:3306/webProject":            
            String dbURL = "jdbc:oracle:thin:@127.0.0.1:1521:XE";            
            String dbUSER = "scott";            
            String dbPASS = "tiger";            
            con = DriverManager.getConnection(dbURL, dbUSER, dbPASS);            
            // System.out.println("DB 연결에 성공했습니다.");                       	
            
            // 4. SQL문을 실행하기 위한 객체를 생성한다.        	
            // - PreparedStatement                       
            // KING: 5000, SCOTT, FORD: 3000            
            pstmt = con.prepareStatement("SELECT * FROM EMP WHERE SAL >= 3000");  // 3명만 출력                    	
            
            // 5. SQL문을 실행한다.                        
            rs = pstmt.executeQuery();                    	
            
            // 6. SQL문의 결과 값을 사용한다.           	
            // - ResultSet            
            while(rs.next()) {            	
                String empno = rs.getString(1);            	
                System.out.println("EMPNO: " + empno);  // 데이터 출력            
            }                                 
        } catch(Exception e) {            
            // e.printStackTrace();        	
            System.out.println(e.getMessage());        
        } finally {
        	// 7. 사용된 객체를 종료한다.         	
            // - ResultSet, PreparedStatement, Connection                      	
            try {            	
                if(rs != null)    { rs.close();    }  // 선택 사항                
                if(pstmt != null) { pstmt.close(); }  // 선택 사항이지만 호출 추천                
                if(con != null)   { con.close();   }  // 필수 사항            
            } catch(SQLException e) {            	
                // e.printStackTrace();            	
                System.out.println(e.getMessage());            
            }        
        }    
    }
}
```

### **2. 자바 파일 컴파일 및 실행 명령어 설명**

**`javac` : 자바소스를 컴파일하는 명령어**
  . 형식: `javac 파일명.java`
  . 컴파일이 완료되면 class 파일이 생성된다.
    . `파일명.java` -> `파일명.class`

**`java` : 자바 클래스 파일을 실행하는 명령어**
  . 형식: `java 파일명`
  . 자바 파일(`파일명.class`)은 단독으로 실행할 수 없고 `java` 명령어로 실행해야 한다.
  . 실행은 `.class` 를 제거하고 파일명만 붙힌다.

### **3. 파일 컴파일 및 실행 테스트**

`JdbcTest.java` 파일을 컴파일한다.

**Oracle JDBC 드라이버가 없는 경우**
```bash
[root@victim ~]# javac JdbcTest.java
[root@victim ~]# java JdbcTest
oracle.jdbc.driver.OracleDriver  <-- Oracle JDBC Driver가 없는 경우에 출력되는 메세지
```

**Oracle JDBC 드라이버가 있는 경우**
  . Oracle JDBC 드라이버를 Java 디렉터리에 복사한다.

```bash
[root@victim ~]# cp ~tomcat/lib/ojdbc6.jar \
/usr/lib/jvm/java-1.8.0-openjdk-1.8.0.262.b10-1.el7.x86_64/jre/lib/ext/
```
