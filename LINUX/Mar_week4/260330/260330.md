################## NAT 설정################

### **Static NAT**
  . 설정 3개 (S셋)
    - NAT 정책 설정 1개, inside, outside

```cisco
!R1
en
conf t   
ip nat inside source static 10.10.10.1 100.100.12.11 
ip nat inside source static 10.10.10.2 100.100.12.12 
ip nat inside source static 10.10.10.3 100.100.12.13     
int fa0/0 
ip nat inside 
int s0/0/0 
ip nat outside
!        
```

### **Dynamic NAT**
  . 설정 5개 (D다섯)
    - ACL 목록 1개, NAT Pool 1개
    - NAT 정책 설정 1개, inside, outside
  . Dynamic NAT는 Static NAT과 다르게 ACL 설정을 할 때는 전체 네트워크를 설정하는 경우에는 아래처럼 설정한다.

```cisco
access-list 1 permit 10.10.10.0 0.0.0.255
```

개별 호스트를 설정하는 경우에는 아래처럼 설정한다.

```cisco
access-list 1 permit host 10.10.10.1 
access-list 1 permit host 10.10.10.2
access-list 1 permit host 10.10.10.3
```

```cisco
!R1 Dynamic NAT 
en
conf t
! access-list 1 permit host 10.10.10.1 
! access-list 1 permit host 10.10.10.2
! access-list 1 permit host 10.10.10.3 
access-list 1 permit 10.10.10.0 0.0.0.255 
ip nat pool nattest 100.100.12.11 100.100.12.13 netmask 255.255.255.0 
ip nat inside source list 1 pool nattest 
int fa0/0 
ip nat inside 
int s0/0/0 
ip nat outside
!
```

```cisco
erase startup-config
reload

!R1 Dynamic NAT 
en 
conf t 
hostname R1 
no ip domain-lookup 
line con 0 
logging synchronous 
exec-timeout 0 0 
exit 
ip route 100.100.20.0 255.255.255.0 100.100.12.2
! access-list 1 permit host 10.10.10.1 
! access-list 1 permit host 10.10.10.2
! access-list 1 permit host 10.10.10.3 
access-list 1 permit 10.10.10.0 0.0.0.255 
ip nat pool nattest 100.100.12.11 100.100.12.13 netmask 255.255.255.0 
ip nat inside source list 1 pool nattest 
int s0/0/0 
ip add 100.100.12.1 255.255.255.0 
no sh 
ip nat outside 
int f0/0 
ip add 10.10.10.254 255.255.255.0 
no sh 
ip nat inside 
end
wr memory
!
```

### **NAT-PAT**
  . **NAT-PAT (Interface지정) 설정 4개**
    - R1의 Interface 에 설정된 IP주소를 가지고 나가지만 포트로 구분해서 다수의 PC가 사용할 수 있게 설정한다.
    - ACL 목록 1개
    - NAT 정책 설정 1개 (overload 추가), inside, outside
  . **NAT-PAT (별도 공인IP지정) 설정 5개 (D다섯)**
    - R1의 Interface 에 설정된 IP주소를 가지고 나가지만 포트로 구분한다.
    - Dynamic NAT와 동일하지만 overload 를 추가한다.
    - ACL 목록 1개, NAT Pool 1개
    - NAT 정책 설정 1개 (overload 추가), inside, outside
  . R1만 설정하면 된다.

```cisco
!R1 NAT-PAT (Interface지정) 
en
conf t
! access-list 1 permit host 10.10.10.1 
! access-list 1 permit host 10.10.10.2
! access-list 1 permit host 10.10.10.3 
access-list 1 permit 10.10.10.0 0.0.0.255 
ip nat inside source list 1 interface Serial0/0/0 overload 
int fa0/0 
ip nat inside 
int s0/0/0 
ip nat outside
!
```

## **실습.[LAB] 동적 라우팅 RIP 설정하기**
파일명: DynamicRoutingRIP1.pkt

```cisco
!R1
en
conf t 
hostname R1 
no ip domain-name 
line con 0 
logging synchronous 
exec-timeout 0 0 
int lo 0
! ip add 192.168.1.1 255.255.255.255 
ip add 192.168.1.1 255.255.255.0 
int fa0/0 
ip add 10.10.10.1 255.255.255.192 
no sh 
int s0/0/0 
ip add 1.1.1.1 255.255.255.252 
no sh 
exit 
router rip 
version 2 
no auto-summary 
passive-interface fa0/0 
network 192.168.1.0 
network 1.0.0.0  
network 10.0.0.0 
end
wr
!
```
