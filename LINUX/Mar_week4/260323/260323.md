### **chmod : 권한 변경**
  . 보안과 연관되어 있기 때문에 100% 알아야 한다.

```bash
    # cp /etc/hosts .
    # LANG=en_US.utf-8
    # ll hosts
    -rw-r--r--. 1 root root 204 Mar 20 17:07 hosts
      u  g  o

              권한 변경
    # chmod u+x hosts;  ll hosts
    # chmod g+wx hosts; ll hosts
    # chmod o+wx hosts; ll hosts
    -rwxrwxrwx. 1 root root 204 Mar 20 17:07 hosts
    # chmod u-x hosts
    # chmod go-x hosts
    # ll hosts
    -rw-rw-rw-. 1 root root 204 Mar 20 17:07 hosts
    # chmod o= hosts -c
    # ll hosts
    -rw-rw----. 1 root root 204 Mar 20 17:07 hosts
    # chmod ug= hosts  -c
    mode of 'hosts' changed from 0660 (rw-rw----) to 0000 (---------)
    # chmod 530 hosts            # r-x-wx---
    # chmod 700 hosts -c         # rwx------
    # chmod 755 hosts -c         # rwxr-xr-x
    # chmod 644 hosts -c         # rw-r--r--
```

### **chown : 소유자 변경**
  . 파일의 소유자를 변경한다.

```bash
    # chown linuxadmin hosts -c    # linuxadmin root
    # chown user1 hosts -c         # user1 root
    # chown root:linuxadmin hosts  # root linuxadmin
    # chown :root hosts            # root root
```

### **chgrp : 그룹 변경**
  . 그룹을 변경한다.

```bash
    # chgrp user1 hosts -c    # user1 user1
```

### **umask : 기본 권한 확인/설정**
  . 파일(모든 파일)을 생성할 때 기본 권한이 설정되어 있다.
    - 기본 권한은 umask 의 설정값에 의해서 생성된다.
    - umask에 설정되어 있는 값이 파일(모든 파일)을 생성할 때 만들어지는 기본 권한
  . 명령어 실행

```bash
    $ help umask or umask --help
        인수가 없으면 display
    $ umask
    0022
```

    디렉터리: rwx 권한을 가질 수 있다.
    실행 파일:rwx
    텍스트 파일(셸스크립트): rwx
    텍스트 파일(문서, 그래픽, 압축): rw-

    . 일반 파일의 권한
```bash
    $ touch a.txt
    $ ll a.txt
    -rw-r--r--. 1 linuxadmin linuxadmin 0 Mar 23 14:21 a.txt

         777
     - 022
     -------
       755
      - 111
     -------
       644  <-- -rw-r--r--
```

    . 디렉터리 파일의 권한
```bash
       777
      -022
      -------
       755   <-- -rwxr-xr-x

    $ mkdir directory
    $ ls -ld directory/
    drwxr-xr-x. 2 linuxadmin linuxadmin 6 Mar 23 14:24 directory/
```

    인수가 있으면 setting
```bash
    $ umask 077
    $ umask
    0077
    $ touch b.txt
    $ mkdir directory2
    $ ls -ld b.txt  directory2/
    -rw-------. 1 linuxadmin linuxadmin 0 Mar 23 14:27 b.txt
    drwx------. 2 linuxadmin linuxadmin 6 Mar 23 14:27 directory2/

    정규 파일  디렉터리 파일
      777        777
      - 077      - 077
      ------     ------
       700        700
      - 100
          -------
          600
```

### **id : UID/GID 확인**
  . 자신의 사용자/그룹 정보를 출력한다.

```bash
    $ id
    uid=1000(linuxadmin) gid=1000(linuxadmin) groups=1000(linuxadmin),10(wheel) context=unconfined ...(생략)...
    $ grep linuxadmin /etc/{passwd,group}
    /etc/passwd:linuxadmin:x:1000:1000:linuxadmin:/home/linuxadmin:/bin/bash
    /etc/group:wheel:x:10:linuxadmin
    /etc/group:linuxadmin:x:1000:
```

     명령어를 실행할 때 연속적으로 실행하는 방법
       . 명령어1; 명령어2; 명령어3; ...
         - 앞에 명령어가 에러(실패)가 발생해도 뒤에 명령어가 실행된다.
       . 명령어1 && 명령어2 && 명령어3 && ...
         - 앞에 명령어가 성공해야 뒤에 명령어가 실행된다.
         - 앞에 명령어가 싶패하면 뒤에 명령어는 실행되지 않는다.

```bash
    $ id; id -u; id -un
    $ id && id -g && id -gn
    $ aaa; pwd; id
    $ aaa && pwd && id
```
