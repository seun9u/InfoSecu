## **실습. [LAB] APM + Tomcat + Oracle 11g XE 완전 삭제하기**

### **1. APM 삭제**

```bash
systemctl stop httpd.service mariadb.service

yum -y remove httpd php php-mysql mariadb mariadb-server \
php-gd gd gd-devel libjpeg libjpeg-devel giflib giflib-devel libpng \
libpng-devel freetype freetype-devel net-tools mod_ssl bash-completion > /dev/null

rm -rf /etc/http*
rm -rf /etc/php*
rm -rf /etc/my*
rm -rf /var/lib/mysql/
rm -rf /var/www/html/

firewall-cmd --permanent --remove-service={http,https}
firewall-cmd --reload
```

---

### **2. Tomcat/Java 삭제**

```bash
systemctl stop tomcat.service
yum -y remove java-1.8.0-openjdk java-1.8.0-openjdk-devel tomcat tomcat-webapps tomcat-admin-webapps \
tomcat-el tomcat-el-2.2-api tomcat-jsp-2.2-api tomcat-servlet-3.0-api
userdel -r tomcat
rm -rf /var/lib/tomcat/

firewall-cmd --permanent --remove-port=8080/tcp
firewall-cmd --reload

```

---

### **3. Oracle 11g XE 삭제**

```bash
/etc/init.d/oracle-xe stop
rpm -e oracle-xe
userdel -r oracle

ls -R /u01
rm -rf /u01/

cd
swapoff swapfile
rm -f swapfile
```
