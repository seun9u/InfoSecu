## **1. 사용자 및 소속 그룹 확인**

### **whoami : 현재 사용자**
* 현재 로그인한 사용자를 확인합니다. (`id -un` 명령어와 결과가 동일합니다.)

```bash
$ whoami
linuxadmin

$ id -un
linuxadmin
```

### **groups : 소속 그룹**
* 자신이 속한 기본 그룹과 보조 그룹을 모두 확인합니다.

```bash
$ groups
linuxadmin wheel

$ id -Gn
linuxadmin wheel

# 특정 사용자의 그룹 확인
$ groups root 
$ groups root user1 
$ groups root user1 linuxadmin
```

## **2. 셸(Shell) 실행 및 그룹 전환**

### **bash : 셸(쉘) 실행**
* 사용자의 명령어를 해석해서 커널에 전달해주는 '명령어 해석기'입니다.
* 로그인을 하면 기본적으로 셸이 실행됩니다.
* 환경변수 `$SHLVL` 을 확인하면 현재 셸이 몇 번 중첩되어 실행되었는지 깊이를 알 수 있습니다.
  * *예시: [login] > [shell 1] > [shell 2] > [shell 3]*

```bash
$ echo $SHLVL
1
$ bash 
$ echo $SHLVL
2
$ bash 
$ echo $SHLVL
3
$ exit
$ echo $SHLVL
2
$ exit
$ echo $SHLVL
1

$ exit
logout
Connection to 192.168.100.3 closed.
```

### **newgrp : 그룹 전환**
* 새로운 그룹으로 변경할 때 사용합니다. 현재 로그인 사용자는 그대로 유지하면서 '기본 그룹'만 변경하여 **새로운 셸을 시작**하는 명령어입니다.
* `newgrp`를 실행하면 일어나는 2가지 변화:
  1. 새로운 셸이 실행됩니다. (기존 셸 위에 새 셸이 하나 더 실행되므로 `SHLVL` 값이 증가)
  2. 기본 그룹(primary group)이 지정한 그룹으로 변경됩니다.

```bash
$ LANG=en_US.utf8
$ echo $SHLVL
1

# 현재 사용자 정보 (gid: 기본 그룹, groups: 기본 + 보조 그룹)
$ id
uid=1000(linuxadmin) gid=1000(linuxadmin) groups=1000(linuxadmin),10(wheel) ...

# 기본 그룹으로 파일 생성
$ touch file1.txt
$ ll file1.txt
-rw-r--r--. 1 linuxadmin linuxadmin 0 Mar 24 09:38 file1.txt

# newgrp를 이용해 기본 그룹을 wheel 그룹으로 변경
$ newgrp wheel
$ echo $SHLVL
2
$ id
uid=1000(linuxadmin) gid=10(wheel) groups=10(wheel),1000(linuxadmin) ...

# 변경된 기본 그룹으로 파일 생성
$ touch file2.txt
$ ll file2.txt
-rw-r--r--. 1 linuxadmin wheel 0 Mar 24 09:40 file2.txt

# 원래 셸로 복귀
$ exit 
$ echo $SHLVL
1
$ id
uid=1000(linuxadmin) gid=1000(linuxadmin) groups=1000(linuxadmin),10(wheel) ...
```

* **참고:** 소속되지 않은 다른 그룹으로 전환하려면 해당 그룹의 비밀번호가 필요합니다.
```bash
$ sudo cat /etc/gshadow
root:::
wheel:::linuxadmin
user1:!::

$ newgrp root
Password:
newgrp: failed to crypt password with previous salt: Invalid argument

$ newgrp user1
Password:
newgrp: failed to crypt password with previous salt: Invalid argument
```

## **3. 사용자 비밀번호 변경**

### **passwd : 사용자 비밀번호 변경**
* 자신의 비밀번호와 다른 사용자의 비밀번호를 변경할 수 있습니다.
* **자신의 비밀번호:** 언제든 변경 가능합니다. (이전 비밀번호 확인 필요)
* **다른 사용자의 비밀번호:** 슈퍼유저(root) 권한이 있어야만 변경할 수 있습니다.

```bash
# 변경 전 암호 정보 확인
$ sudo grep linuxadmin /etc/shadow
linuxadmin:$6$bwLH4OrxuCfvHfxw$4y5swdXumefJ4FfNrNzNYOm/XbV/8bmL2GAW ... ::0:99999:7:::

# 비밀번호 변경 시도 (기존 암호 틀림)
$ passwd
Changing password for user linuxadmin.
Current password:  <-- 비밀번호가 틀리면 종료됨
passwd: Authentication token manipulation error

# 비밀번호 변경 성공
$ passwd
Changing password for user linuxadmin.
Current password:  <-- 비밀번호가 맞으면 새로운 비밀번호 입력을 받음
New password:
Retype new password:
passwd: all authentication tokens updated successfully.

# 변경 후 암호 정보 확인
$ sudo grep linuxadmin /etc/shadow
linuxadmin:$6$rounds=100000$6YypYhS2i8veN9/4$uGjwSICcLFvZmjq9.Re4UF111/Vuc3DL...:20536:0:99999:7:::

# 일반 사용자가 다른 사용자의 비밀번호 변경 시도 시 에러
$ passwd user1
passwd: Only root can specify a user name.
```
