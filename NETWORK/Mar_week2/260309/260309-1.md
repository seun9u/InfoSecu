# 🏷️ VLAN 태깅 원리 및 Inter-VLAN Routing (ROAS) 상세 정리

## 1. VLAN 태깅(Tagging) 동작 방식
VLAN 태깅은 프레임이 어떤 VLAN에 속해 있는지 식별하기 위해 데이터에 표식을 남기는 과정입니다.

* **태깅 및 제거 원리**:
    * 스위치에 프레임이 들어오면 스위치가 해당 VLAN 정보를 태깅합니다.
    * **Access 포트**로 나갈 때는 VLAN 태깅을 제거하고 전송합니다.
    * **Trunk 포트**로 나갈 때는 반대편 스위치에서도 VLAN을 식별해야 하므로 태깅을 제거하지 않고 전송합니다.
* **IEEE 802.1Q 표준**: 
    * Source MAC과 Ether Type 사이에 **4바이트**의 VLAN 정보를 추가합니다.
    * **VLAN ID(VID)**는 **12비트**를 사용하며, 이로 인해 생성 가능한 VLAN ID 범위는 **1-4094**입니다.



---

## 2. Trunk 포트 설정의 특징
* **자동 vs 수동**: 한쪽을 Trunk로 설정하면 반대편이 자동으로 설정될 수 있지만, 관리의 명확성을 위해 양쪽 모두 **수동으로 설정**하는 것이 좋습니다.

---

## 3. Inter-VLAN Routing: ROAS (Router-on-a-stick)
서로 다른 VLAN 간 통신을 위해 라우터의 물리 인터페이스 하나를 논리적으로 나누어 사용하는 방식입니다.

* **개념**: 라우터가 하나의 링크(Stick)에 의지해 여러 VLAN을 처리한다고 해서 붙여진 이름입니다.
* **설정 요소**:
    * 라우터의 물리 인터페이스 1개에 여러 개의 **서브인터페이스**를 생성합니다.
    * **802.1Q Trunk** 설정을 통해 VLAN 태그를 인식하게 합니다.
    * 각 서브인터페이스에 IP 주소를 설정하여 각 VLAN의 **기본 게이트웨이** 역할을 수행합니다.



---

## 4. 실습.[LAB] ROAS 인터페이스 설정

라우터 인터페이스 설정 시 **IP 주소 설정과 활성화(no shutdown)**의 순서는 바뀌어도 상관없습니다.

```ios
! --- ROAS 설정 시작 ---
en
conf t

! 1. 물리 인터페이스 활성화
int fa0/0
 no sh

! 2. VLAN 10용 서브인터페이스 설정
int fa0/0.10
 encapsulation dot1Q 10
 ip add 10.10.10.254 255.255.255.0

! 3. VLAN 20용 서브인터페이스 설정
int fa0/0.20
 encapsulation dot1Q 20
 ip add 10.10.20.254 255.255.255.0
! --- 설정 완료 ---
```
