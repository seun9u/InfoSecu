# 🌐 실습. [LAB] 서브넷을 이용한 네트워크 구성하기 (p.151)

## 1. 네트워크 서브네팅 (Subnetting) 분석
`192.168.10.0/24` 네트워크를 4개의 서브넷으로 분할하기 위해 호스트 비트 2개를 빌려 `/26`으로 서브네팅합니다.

* **서브넷 마스크**: `255.255.255.192` (/26)

| 네트워크 순서 | 네트워크 주소 (2진수 범위) | IP 범위 (10진수) | 비고 |
| :--- | :--- | :--- | :--- |
| **Network #1** | 192.168.10.**00**000000 ~ 111111 | 192.168.10.0 ~ 63 | - |
| **Network #2** | 192.168.10.**01**000000 ~ 111111 | 192.168.10.64 ~ 127 | **A기관 할당** |
| **Network #3** | 192.168.10.**10**000000 ~ 111111 | 192.168.10.128 ~ 191 | - |
| **Network #4** | 192.168.10.**11**000000 ~ 111111 | 192.168.10.192 ~ 255 | **B기관 할당** |

---

## 2. 기관별 IP 할당 계획 상세

### [A기관] (Network #2 사용)
* **네트워크 주소**: `192.168.10.64/26`
* **가용 IP 범위**: `192.168.10.65 ~ 192.168.10.126`
* **브로드캐스트 주소**: `192.168.10.127`
* **주요 할당**:
    * **R1 Fa0/0 (Gateway)**: `192.168.10.65`
    * **SW1 관리용 IP**: `192.168.10.67`

### [B기관] (Network #4 사용)
* **네트워크 주소**: `192.168.10.192/26`
* **가용 IP 범위**: `192.168.10.193 ~ 192.168.10.254`
* **브로드캐스트 주소**: `192.168.10.255`
* **주요 할당**:
    * **R1 Fa0/1 (Gateway)**: `192.168.10.193`
    * **SW2 관리용 IP**: `192.168.10.195`

---

## 3. 장비별 상세 설정 스크립트



### 📍 R1 (라우터) 설정
```ios
en
conf t
hostname R1
no ip domain-lookup
line con 0
 logging synchronous
 exec-timeout 0 0  // 실습 시 자동 로그아웃 방지

! A기관 게이트웨이 설정
int fa0/0
 ip add 192.168.10.65 255.255.255.192
 no sh

! B기관 게이트웨이 설정
int fa0/1
 ip add 192.168.10.193 255.255.255.192
 no sh

end
wr
```

### 📍 SW1 (A기관 스위치) 설정
```ios
en
conf t
hostname SW1
no ip domain-lookup
line con 0
 logging synchronous
 exec-timeout 0 0

! 관리용 IP 및 디폴트 게이트웨이 설정
ip default-gateway 192.168.10.65
int vlan 1
 ip add 192.168.10.67 255.255.255.192
 no sh
end
wr
```

### 📍 SW2 (B기관 스위치) 설정
```ios
en
conf t
hostname SW2
no ip domain-lookup
line con 0
 logging synchronous
 exec-timeout 0 0

! 관리용 IP 및 디폴트 게이트웨이 설정
ip default-gateway 192.168.10.193
int vlan 1
 ip add 192.168.10.195 255.255.255.192
 no sh
end
wr
```
