# 🌐 실습. [LAB] 서브넷을 이용한 네트워크 구성하기 (p.148)

## 1. 네트워크 서브네팅 (Subnetting) 분석
기존 C클래스 대역(`192.168.100.0/24`)을 `/25`로 나누어 두 개의 서브넷으로 분리합니다.

* **네트워크 대역: `192.168.100.0/25`**
    * **서브넷 마스크**: `255.255.255.128`
    * **첫 번째 서브넷**: `192.168.100.0 ~ 127` (0: 네트워크 이름, 127: 브로드캐스트로 사용 불가)
    * **두 번째 서브넷**: `192.168.100.128 ~ 255` (128: 네트워크 이름, 255: 브로드캐스트로 사용 불가)

---

## 2. 기관별 게이트웨이 및 IP 할당 계획

### [A기관]
* **네트워크**: `192.168.100.0` (사용 불가)
* **PC1 Gateway**: `192.168.100.1` (가용 가능한 첫 번째 IP)
* **가용 주소 2**: `192.168.100.2`
* **SW1 관리용 IP**: `192.168.100.3` (가용 가능한 세 번째 IP)

### [B기관]
* **네트워크**: `192.168.100.128` (사용 불가)
* **PC2 Gateway**: `192.168.100.129` (가용 가능한 첫 번째 IP)
* **가용 주소 2**: `192.168.100.130`
* **SW2 관리용 IP**: `192.168.100.131` (가용 가능한 세 번째 IP)

---

## 3. 장비별 상세 설정 스크립트



### 📍 R1 (라우터) 설정
```ios
en
conf t
hostname R1
no ip domain-lookup
line con 0
 logging synchronous
 exec-timeout 0 0  // 실습 편의를 위한 자동 로그아웃 방지

! A기관 연결 인터페이스
int fa0/0
 ip add 192.168.100.1 255.255.255.128
 no sh

! B기관 연결 인터페이스
int fa0/1
 ip add 192.168.100.129 255.255.255.128
 no sh

end
wr
sh ip int b
```

### 📍 SW1 (A기관 스위치) 설정
```ios
en
conf t
hostname SW1
no ip domain-lookup
line con 0
 logging synchronous
 exec-timeout 0 0
 
! 관리용 IP 및 게이트웨이 설정
ip default-gateway 192.168.100.1
int vlan 1
 ip add 192.168.100.3 255.255.255.128
 no sh
end
wr
```
