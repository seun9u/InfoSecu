## DHCP (Dynamic Host Configuration Protocol) 개요

DHCP는 IP 주소 풀(Pool)을 가지고 있다가 클라이언트가 IP 주소를 요청하면, 임대하고 남은 IP 주소를 클라이언트에게 전송해 주는 프로토콜입니다. 클라이언트는 서버에서 이 정보를 받아 자신의 네트워크를 설정합니다.

**📍 구현 방법**
* **라우터에서 구현**: 클라이언트가 많아지면 라우터에 부하가 발생할 수 있는 단점이 있습니다.
* **서버에서 구현**: 라우터 부하를 줄이기 위해 별도의 서버 장비로 구현하는 것을 권장합니다.

## 실습.[LAB] Server 설정하기

이번 랩(LAB)에서는 아래의 세 가지 서버를 구현합니다.

1. **DHCP Server**
   * UDP를 사용합니다.
   * 네트워크 정보(IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 주소)를 임대해 주는 서버입니다.
2. **DNS Server**
   * 도메인 주소를 IP 주소로 변환하여 알려주는 서버입니다.
   * DNS 도메인 요청은 기본적으로 UDP를 사용하지만, 응답 패킷 크기가 512Byte를 넘거나 영역(Zone) 전송을 할 때는 TCP를 사용합니다.
3. **WEB Server**
   * 웹 데이터를 전송하는 서버입니다.
   * HTTP/1.1 버전의 요청과 응답은 TCP를 사용합니다.

### 📍 DHCP 동작 과정 (DORA)
DHCP는 DORA(도라에몽) 과정을 거쳐 IP를 할당합니다.

* **D**iscover (Broadcast): `Client 전송` - 동일 네트워크에서 DHCP 서버를 찾기 위해 보내는 패킷
* **O**ffer (Broadcast): `Server 전송` - Discover를 받은 서버가 클라이언트에게 네트워크 정보를 제안하는 패킷
* **R**equest (Broadcast): `Client 전송` - Offer 받은 정보의 사용을 서버에 요청하는 패킷
* **A**cknowledgment (Broadcast): `Server 전송` - 서버가 확인했음을 클라이언트에게 최종적으로 알려주는 패킷

  * Name: `naver.com` / Address: `192.168.100.133` → [Add]
  * Name: `www.naver.com` / Address: `192.168.100.133` → [Add]
  * Name: `daum.net` / Address: `192.168.100.132` → [Add]
  * Name: `www.daum.net` / Address: `192.168.100.132` → [Add]
  * Name: `mynetwork.com` / Address: `192.168.100.4` → [Add]
  * Name: `www.mynetwork.com` / Address: `192.168.100.4` → [Add]

**📍 CMD에서 DNS Resource Record(RR) 확인 (nslookup 테스트)**
```cmd
C:\Users\ITSC>nslookup

> set type=a

          223.130.200.219
          223.130.192.248
          223.130.200.236

> exit
```
*(참고: set type 옵션을 aaaa, cname, ns, soa 등으로 변경하여 다양한 레코드를 조회할 수 있습니다.)*

### 3. WEB Server 구현

웹서버는 도메인별로 3개를 구현합니다.
* **WEB1**: naver.com (192.168.100.133)
* **WEB2**: daum.net (192.168.100.132)
* **WEB3**: mynetwork.com (192.168.100.4)

#### WEB1 Server (naver.com)
* **네트워크 설정**: IP 192.168.100.133 / SM 255.255.255.192 / GW 192.168.100.129 / DNS 192.168.100.132

* `index.html` 파일만 남기고 모두 삭제 후 (edit) 클릭
* 내용 수정: `네이버에 오신 것을 환영합니다.` → [Save]

#### WEB2 Server (daum.net)
