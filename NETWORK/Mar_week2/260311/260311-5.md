## 포트 시큐리티 (Port Security)

포트 시큐리티는 스위치 포트에 허용할 MAC 주소를 제한해서 허가되지 않은 장비가 연결되는 것을 막는 L2의 MAC주소 보안 기능입니다. 특정 스위치 포트에 정해진 PC 1대만 연결되게 하거나 허용된 MAC 주소만 통신을 가능하게 하는 기능으로, 다른 장비가 연결되면 차단, 로그, 셧다운을 하도록 설정합니다.


### 1. 포트 시큐리티를 사용하는 목적
* 사무실에서 어떤 사용자가 자기 노트북이나 허브를 몰래 연결하여 발생하는 문제를 방지하기 위해 사용합니다.
* 큰 기업들은 NAC 장비를 사용합니다. (네트워크 참여 전 인증 필수, 예: 카페 와이파이 인증과 동일한 원리)
* 포트 시큐리티를 통해 다음과 같은 기능이 가능합니다:
  * 임의 장비 연결 방지
  * 허브/스위치 연결 방지
  * MAC 주소 기반 단말 통제
  * 내부 네트워크 접근 제한

### 2. 주요 특징 및 설정 요소
* **동작 환경**: L2단 Access 모드에서 사용합니다. (L3 스위치에서 `no switchport`를 사용하면 이 기능을 사용할 수 없음)
* **최대 허용 MAC 개수 (`maximum`)**: 포트에 몇 개의 MAC 주소를 허용할지 설정합니다.
  * 예) `maximum 1` → PC 1대만 허용
  * 예) `maximum 2` → IP Phone + PC 같이 2개 허용 가능
* **허용 MAC 주소 등록 방식**:
  * **정적 (Static)**: 관리자가 직접 MAC 주소를 입력합니다.
  * **동적 학습 (Dynamic)**: 처음 들어온 MAC을 학습합니다.
  * **Sticky**: 처음 들어온 MAC을 자동 학습해서 running-config에 저장하며 실무에서도 많이 사용합니다.
* **위반 시 동작 (Violation Mode)**:
  * **protect**: 허용되지 않은 MAC 프레임을 조용히 폐기합니다. (로그 거의 없고 포트는 살아있음)
  * **restrict**: 허용되지 않은 MAC 프레임을 폐기하고 카운터를 증가시킵니다. (로그/SNMP trap 가능)
  * **shutdown**: 가장 많이 언급되는 기본 방식입니다. 위반 발생 시 포트를 `err-disabled` 상태로 내리며 사실상 포트가 꺼집니다.

### 3. 설정 예시 및 주의사항

**📍 기본 설정 예시**
```ios
en
conf t
int fa0/0
switchport mode access                      ! access 포트로 설정
switchport port-security                    ! 포트 시큐리티 활성화
switchport port-security maximum 1          ! MAC 주소 1개만 허용
switchport port-security violation shutdown ! 위반 시 포트 shutdown
switchport port-security mac-address sticky ! 처음 연결된 MAC 주소를 자동 학습
end  
```

**📍 위반 후 복구 방법**
```ios
conf t
int fa0/1
shutdown
no shutdown
end
```

**📍 주의사항**
* **Trunk 포트 사용 지양**: 포트 시큐리티는 일반적으로 access 포트용입니다.
* **PC 교체 시 위반 주의**: sticky로 학습된 MAC 때문에 새 PC(예: 대표님 노트북 등)가 연결되면 위반이 나서 통신이 안 될 수 있습니다.
* **설정 저장 필수**: sticky MAC은 `running-config`에 반영되므로 유지하려면 반드시 저장해야 합니다. (예: `wr`, `copy running-config startup-config`)

## 실습.[LAB] 포트 시큐리티

**실습 목표**
* 스위치의 특정 포트에 허용된 MAC 주소만 접속 가능하게 설정한다.
* 다른 PC가 연결되면 위반(violation)이 발생하는 것을 확인한다.
* shutdown 모드에서 포트가 차단되는 것을 확인한다.

### 1. DHCP 설정
* **DHCP (Dynamic Host Configuration Protocol)**: IP 주소 풀을 가지고 있다가 DHCP 클라이언트가 IP 주소를 요청하면 임대하고 남은 IP 주소를 전송합니다. 클라이언트는 서버에서 받아서 자신의 네트워크를 설정합니다.


**📍 Services > DHCP 설정값**
* **상태**: On으로 설정
* **Pool Name**: serverPool
* **Default Gateway**: 192.168.3.1
* **DNS Server**: 192.168.3.2
* **Start IP Address**: 192.168.3.128
* **Subnet Mask**: 255.255.255.0
* **Maximum Number of Users**: 30
* 설정 후 **[Save]**

### 2. 스위치 (SW0) 설정 스크립트

```ios
! SW0 초기 설정 및 포트 시큐리티 적용
en
conf t
 hostname SW0
 no ip domain-lookup
 line con 0
 logging synchronous
 exec-timeout 0 0
 int fa0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
 end
wr

! 포트 시큐리티 확인 및 MAC 주소 초기화 후 재설정
en
show port-security address 
conf t
int fa0/1
 no switchport port-security mac-address sticky
 shutdown
 no shutdown
 switchport port-security mac-address sticky
```
