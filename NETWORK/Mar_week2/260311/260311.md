## 5. F기관(VLAN) 및 E기관(연결 구간) 상세 분석

### 📍 E기관 (Network #5 - R2와 R4 연결 구간)
* **2진수 범위**: 1.1.1.000010 **00** (8) ~ 1.1.1.000010 **11** (11)
* **네트워크 대역**: `1.1.1.8 ~ 1.1.1.11 /30`
* **가용 IP 주소**: `1.1.1.9` (R2 Fa1/0) ~ `1.1.1.10` (R4 Fa0/1)

### 📍 F기관 (VLAN 네트워크 - Router-on-a-Stick)
* **VLAN 10**: `10.10.10.0 /24` (가용 IP: 10.10.10.1 ~ 10.10.10.253)
* **VLAN 20**: `10.10.20.0 /24` (가용 IP: 10.10.20.1 ~ 10.10.20.253)
* **Gateway**: VLAN 10 (`10.10.10.254`), VLAN 20 (`10.10.20.254`)

## 6. F기관용 라우터(R4) 및 스위치 설정

### 📍 R4 설정 (ROAS 및 E구간 연결)
R4는 내부 VLAN 간 라우팅을 위해 서브 인터페이스를 설정하고, 외부로 나가는 경로를 지정합니다.

```ios
en
conf t
 hostname R4

! 물리 포트 활성화
int fa0/0
 no sh

! VLAN 10 게이트웨이 설정 (ROAS)
int fa0/0.10
 encapsulation dot1Q 10
 ip add 10.10.10.254 255.255.255.0

! VLAN 20 게이트웨이 설정 (ROAS)
int fa0/0.20
 encapsulation dot1Q 20
 ip add 10.10.20.254 255.255.255.0

! R2 연결 포트 설정 (E기관)
int fa0/1
 ip add 1.1.1.10 255.255.255.252
 no sh
exit

! 정적 라우팅 (상위 네트워크 A, B로 가는 길)
ip route 192.168.100.0 255.255.255.0 1.1.1.9
end
wr
```

### 📍 SW1/2 (F기관 스위치) 설정
사용자 포트에 VLAN을 할당하고 라우터와 연결된 포트를 트렁크(Trunk)로 설정합니다.

```ios
en
conf t
 hostname SW1/2
vlan 10
 name v10
vlan 20
 name v20
exit

! PC 연결 포트 (Access 모드)
int fa0/1
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast

int fa0/2
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast

! 라우터 연결 포트 (Trunk 모드)
int range fa0/23-24
 switchport mode trunk
end
wr
```

## 7. 기존 라우터(R1, R2) 추가 경로 설정
새로 추가된 F기관(10.10.x.x)으로 패킷이 갈 수 있도록 중간 라우터들에 경로를 업데이트합니다.

### 📍 R1 추가 설정 (VLAN 대역 경로 추가)
```ios
en
conf t
! VLAN 10, 20 네트워크를 R2(1.1.1.2)를 통해 가도록 설정
ip route 10.10.10.0 255.255.255.0 1.1.1.2
ip route 10.10.20.0 255.255.255.0 1.1.1.2
end
wr
```

### 📍 R2 추가 설정 (VLAN 대역 경로 추가)
```ios
en
conf t
! Fa1/0 포트에 E기관 IP 할당
int fa1/0
 ip add 1.1.1.9 255.255.255.252
 no sh
exit

! VLAN 10, 20으로 가는 정적 라우팅 설정
ip route 10.10.10.0 255.255.255.0 1.1.1.10
ip route 10.10.20.0 255.255.255.0 1.1.1.10
end
wr
```
