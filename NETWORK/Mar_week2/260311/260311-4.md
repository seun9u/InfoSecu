## 실습.[LAB] VLAN 2,3,4 생성

### 1. VLAN 생성

```ios
!VTPServer
en
conf t
 vlan 2
 name VLAN2
 vlan 3
 name VLAN3
 vlan 4
 name VLAN4
 end
!
```

### 2. VLAN/VTP 확인

Server에서 VLAN2, VLAN3, VLAN4가 생성된 것을 확인할 수 있다.

```ios
VTPServer#sh vlan b
2    VLAN2                            active    
3    VLAN3                            active    
4    VLAN4                            active  
```

Configuration Revision 번호가 11 로 확인되었다.

```ios
VTPServer#sh vtp status 
Configuration Revision            : 11
```

VTPClient1,2 에서는 Configuration Revision 번호가 Server와 동일하게 11 이라는 것을 확인할 수 있다.

```ios
VTPClient1#sh vtp status
Configuration Revision            : 11

VTPClient2#sh vtp status
Configuration Revision            : 11
```

VTPClient1,2 에서는 Server에서 전달한 정보를 바탕으로 VLAN2, VLAN3, VLAN4가 생성된 것을 확인할 수 있다.

```ios
VTPClient1#sh vlan b
2    VLAN2                            active    
3    VLAN3                            active    
4    VLAN4                            active    

VTPClient2#sh vlan b
2    VLAN2                            active    
3    VLAN3                            active    
4    VLAN4                            active
```
