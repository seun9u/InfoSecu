## 실습.[LAB] 아래 조건에 맞는 ACL 설정하기

### 1. 조건 확인
* **네트워크**: Network #1 (192.168.100.0/26)  
* **ACL 번호**: 1
* **SSH 접속 금지 호스트**: 192.168.100.2, 192.168.100.4
* **SSH 접속 허용 호스트**: 192.168.100.30
* **기타 조건**: ACL 하단에 눈에 보이지 않는 암묵적인 `deny any`에 의존하지 않고, 명시적으로 `deny any` 룰을 설정하여 나머지 접속을 모두 거부시킵니다.

---

### 2. R1 라우터 ACL 설정 스크립트

```ios
! 거부 호스트 및 허용 호스트 설정
R1(config)#access-list 1 deny host 192.168.100.2
R1(config)#access-list 1 deny host 192.168.100.4
R1(config)#access-list 1 permit host 192.168.100.30

! 설정 확인 (이 상태에서도 암묵적인 deny any가 적용됨)
R1(config)#do sh access-lists
Standard IP access list 1
    10 deny host 192.168.100.2
    20 deny host 192.168.100.4
    30 permit host 192.168.100.30

! 명시적 deny any 추가
R1(config)#access-list 1 deny any
R1(config)#do sh access-lists
Standard IP access list 1
    10 deny host 192.168.100.2
    20 deny host 192.168.100.4
    30 permit host 192.168.100.30
    40 deny any
    
! vty 라인에 ACL 적용
R1(config)#line vty 0 4
R1(config-line)#access-class 1 in
R1(config-line)#do sh run | section vty
line vty 0 4
 access-class 1 in
 login local
 transport input ssh
```

### 3. 접속 테스트 결과
* **192.168.100.2 (PC1) 접속 시도**: `% Connection refused by remote host` (거부)
* **192.168.100.4 (DHServer) 접속 시도**: `% Connection refused by remote host` (거부)
* **192.168.100.30 (Laptop1) 접속 시도**: `Password:` 창 확인됨 (허용)

## 실습.[LAB] 기존 룰에 추가하기

### 1. 잘못된 위치에 룰 추가 시 문제점 확인
`deny any` 룰 밑에 새로운 허용 룰이 들어가면, 라우터는 위에서부터 순차적으로 조건을 검사하므로 패킷이 이미 `deny any`에서 운명이 결정(폐기)되어 아래 룰은 무시됩니다.

```ios
! 192.168.100.3 허용 룰을 마지막에 추가하는 경우
R1(config)#access-list 1 permit host 192.168.100.3
R1(config)#do sh access-lists
Standard IP access list 1
    10 deny host 192.168.100.2 (5 match(es))
    20 deny host 192.168.100.4 (5 match(es))
    30 permit host 192.168.100.30 (2 match(es))
    40 deny any (10 match(es))     <-- 패킷이 여기서 거부됨
    50 permit host 192.168.100.3   <-- 추가된 룰은 의미가 없어짐
```
* **192.168.100.3 (SW3) 접속 시도**: `% Connection refused by remote host` (접속 실패)

---

### 2. 중간 룰 번호를 사용하여 올바르게 룰 삽입하기
192.168.100.3 (SW3) 접속 허용 룰을 10번과 20번 사이인 **11번**으로 추가합니다. 이미 50번으로 잘못 등록된 룰은 삭제한 후 추가해야 합니다.

```ios
! Standard ACL 상세 설정 모드로 진입
R1(config)#ip access-list standard 1

! 기존 50번 룰 삭제 후 11번으로 재등록
R1(config-std-nacl)#no 50 permit host 192.168.100.3
R1(config-std-nacl)#11 permit host 192.168.100.3
R1(config-std-nacl)#exit

! 최종 ACL 목록 확인
R1(config)#do sh ip access-lists
Standard IP access list 1
    10 deny host 192.168.100.2 (5 match(es))
    11 permit host 192.168.100.3
    20 deny host 192.168.100.4 (5 match(es))
    30 permit host 192.168.100.30 (2 match(es))
    40 deny any (15 match(es))
```

### 3. 최종 재접속 테스트
```ios
! 192.168.100.3 (SW3)에서 R1 라우터로 SSH 접속 재시도
SW3#ssh -l admin 192.168.100.1

Password: 
R1>en
Password: 
R1#
```
*(정상적으로 접속이 허용됨을 확인)*
