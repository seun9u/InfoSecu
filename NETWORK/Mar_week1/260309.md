# 🌐 네트워크 핵심 개념 체크리스트 및 VLAN 구축 실습

## 1. 네트워크 기초 개념 요약

| 질문 | 답변 핵심 내용 |
| :--- | :--- |
| **LAN이란?** | 작은 지역의 네트워크를 말하며, 지역 네트워크 담당자가 관리합니다. |
| **WAN이란?** | 큰 규모의 네트워크를 말하며, ISP 업체가 관리합니다. |
| **ISP란?** | Internet Service Provider(통신사업자)의 약자입니다. (예: KT, SK, LG) |
| **프로토콜이란?** | 서버 간의 통신 약속입니다. (예: 웹 통신을 위한 HTTP/HTTPS) |
| **Ethernet이란?** | LAN 구간에서 통신할 때 사용하는 프로토콜입니다. |
| **ARP란?** | IP 주소는 알지만 상대방의 MAC 주소를 모를 때 이를 알아오는 프로토콜입니다. |
| **L3 스위치 기능** | L2 스위치와 라우터 기능을 결합한 장비입니다. `no switchport` 설정으로 포트에 IP를 부여하거나 `ip routing`으로 라우팅을 활성화할 수 있습니다. |

## 2. 장비 관리 및 스위치 기능

### 📍 라우터 인터페이스 네트워크 설정 (R1 예시)
* **FastEthernet 0/0**: `en` > `conf t` > `int f0/0` > `ip add 192.168.1.1 255.255.255.0` > `no sh`
* **FastEthernet 0/1**: `en` > `conf t` > `int f0/1` > `ip add 192.168.1.1 255.255.255.0` > `no sh`

### 📍 스위치 MAC 주소 테이블 관리
* **확인**: `show mac-address-table` 또는 `show mac address-table`
* **삭제**: `clear mac-address-table` 또는 `clear mac address-table`

### 📍 스위치의 5가지 핵심 기능
1. **Address Learning**: 출발지 MAC 주소를 학습하여 테이블에 저장.
2. **Flooding**: 목적지를 모를 때 수신 포트를 제외한 모든 포트로 전송.
3. **Forwarding**: 목적지 주소를 알 때 해당 포트로만 전송.
4. **Filtering**: 다른 포트로 신호가 가지 않도록 차단.
5. **Aging**: 일정 시간 통신이 없으면 테이블에서 주소 삭제.

## 3. 실습.[LAB] VLAN 및 Trunk 구축 (115page)



### ① SW1 및 SW2 설정 (VLAN 생성 및 포트 할당)
두 스위치에 동일하게 VLAN 10(swteam)과 VLAN 20(designteam)을 생성하고, PC 연결 포트는 Access, 스위치 간 연결 포트는 Trunk로 설정합니다.

```ios
! SW1 & SW2 공통 설정
en
conf t
 hostname SW1 (또는 SW2)
 no ip domain-lookup
 line con 0
  logging synchronous
 exit

! VLAN 생성
 vlan 10
  name swteam
 vlan 20
  name designteam

! 포트 할당
 int fa0/1
  switchport mode access
  switchport access vlan 10
 int fa0/2
  switchport mode access
  switchport access vlan 20

! 트렁크(Trunk) 설정 (스위치 간 연결)
 int fa0/24
  switchport mode trunk
 end
wr
show vlan brief
```

## 4. 통신 확인 (Ping Test)

VLAN 설정과 Trunk 연결이 완료되면 동일한 VLAN에 속한 장비끼리 통신이 가능해집니다.

* **VLAN 10 통신 확인 (PC1 -> 상대측 PC)**
  - `C:\> ping 10.10.10.2` ➔ **Reply 수신 (성공)**
* **VLAN 20 통신 확인 (PC2 -> 상대측 PC)**
  - `C:\> ping 10.10.20.2` ➔ **Reply 수신 (성공)**

> **참고**: 서로 다른 VLAN(예: PC1에서 PC2로)은 L3 장비(라우터 또는 L3 스위치)를 통한 라우팅 설정 없이는 통신이 불가능합니다.
