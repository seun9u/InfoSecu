## 실습.[LAB] VTP Version 변경하기 

Switch 하나를 분리하여 단독으로 변경 실습을 진행합니다.

### 📍 VTP Version 변경 제약 사항
* **변경 가능**: `Server`, `Transparent` 모드
* **변경 불가**: `Client` 모드 (직접 수정 시 에러 발생)

---

### 1. VTP Server 모드일 때 (버전 변경 가능)

### 2. VTP Client 모드일 때 (버전 변경 불가)
클라이언트 모드에서는 버전을 직접 수정할 수 없으며 에러 메시지가 출력됩니다.

```ios
Switch(config)# vtp mode client
Setting device to VTP CLIENT mode.
Switch(config)# vtp version 2
Cannot modify version in VTP client mode

Switch(config)# do show vtp status
VTP Version capable             : 1 to 2
VTP version running             : 1
VTP Domain Name                 : 
VTP Pruning Mode                : Disabled
VTP Traps Generation            : Disabled
Device ID                       : 0004.9A71.0A00
Configuration last modified by 0.0.0.0 at 3-1-93 00:01:09

Feature VLAN : 
--------------
VTP Operating Mode                : Client
Maximum VLANs supported locally   : 255
Number of existing VLANs          : 5
Configuration Revision            : 2
MD5 digest                        : 0xF4 0x8E 0xAE 0xAD 0x6D 0x0B 0x9D 0xFB 
                                    0x5D 0x2F 0xE9 0x44 0x35 0x6A 0x22 0x40 
```
