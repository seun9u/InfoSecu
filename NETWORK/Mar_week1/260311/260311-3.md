## 실습.[LAB] VTP 설정하기

스위치를 여러 개 연결해서 실습을 진행하며, 이후 실습은 연속적으로 이어서 설정합니다.

**[VTPSERVER]-----[VTPClient1]-----[VTPTransparent1]-----[VTPClient2]-----[VTPTransparent2]**

### 1. VTP 모드 설정
VTP 모드를 설정합니다. 설정하지 않으면 기본값은 Server 모드입니다. 아래 내용들은 `sh vtp status`로 확인할 수 있습니다.

**📍 VTP 기본 설정 값**
* **VTP Version**: version 1
* **VTP Domain Name**: null
* **VTP Mode**: Server
* **Configuration Revision**: 0

**📍 vtp mode별 특징**
* **server**: VLAN 생성/삭제/이름변경 가능 (기본값)
* **client**: VLAN 생성/삭제 불가능, 서버 정보를 자신의 스위치에 설정
* **transparent**: 독립적으로 동작, 서버 정보를 자신의 스위치에 설정하지 않음

---

### 📍 장비별 상세 설정 스크립트

#### !VTPServer 설정
```ios
VTPServer# show vtp status
! (기본값: Version 1, Domain null, Mode Server 확인)

VTPServer# configure terminal
VTPServer(config)# line con 0
VTPServer(config-line)# logging synchronous
VTPServer(config-line)# exec-timeout 0 0 
VTPServer(config-line)# exit

VTPServer(config)# vtp version 2
VTPServer(config)# vtp mode server
VTPServer(config)# vtp domain mynetwork
VTPServer(config)# vtp password cisco
VTPServer(config)# interface fa0/1
VTPServer(config-if)# switchport mode trunk
VTPServer(config-if)# end
VTPServer# write
```

#### !VTPClient1 설정
```ios
en
conf t
 hostname VTPClient1
 no ip domain-lookup
 line con 0
  logging synchronous
  exec-timeout 0 0
 vtp version 2
 vtp mode client
 vtp domain mynetwork
 vtp password cisco
 interface range fa0/1-2
  switchport mode trunk
 end
wr
```

### 2. VLAN 생성 및 전파 확인
VTPServer에서 VLAN을 생성하고 정보가 어떻게 반영되는지 확인합니다.

```ios
VTPServer(config)# vlan 10 
VTPServer(config-vlan)# do sh vtp status
! Configuration Revision : 1 (생성)

VTPServer(config-vlan)# name vlan10
VTPServer(config-vlan)# do sh vtp status
! Configuration Revision : 2 (이름 변경)
```

**📍 동기화 결과 확인 (show vlan brief)**
* **VTPClient1 / VTPClient2**: `10 vlan10 active` 가 자동으로 생성됨 확인.
* **VTPTransparent1 / VTPTransparent2**: VLAN 10이 생성되지 않고 기본 VLAN들만 존재함 확인.

### 3. 실습.[LAB] VLAN 삭제

서버에서 VLAN 10을 삭제한 후 각 장비의 상태를 확인합니다.

```ios
VTPServer(config)# no vlan 10
VTPServer(config)# do sh vtp status
! Configuration Revision : 5 (삭제 반영 후)

VTPServer(config)# do sh vlan brief
! (VLAN 10 삭제됨 확인)
```

**📍 모드별 최종 상태 (show vtp status)**

* **VTPClient1 / VTPClient2** (서버와 동기화됨)
  - Number of existing VLANs : 5
  - Configuration Revision : 5
  - VLAN 10 삭제됨 확인

* **VTPTransparent1 / VTPTransparent2** (영향 받지 않음)
  - Configuration Revision : 0
  - (서버의 영향을 받지 않아 Revision이 0으로 유지됨 확인)
