  . line vty 0 4
    - 전체 세션 수: 0 ~ 15 까지 총 16개 세션이 존재한다.

사용자 생성
 - 이전 telnet은 사용자가 없고 비밀번호만 존재한다.
   - 비밀번호(password, secret)
 - 장비에 접속하는 사용자를 생성한다.
 - 형식: username <사용자명> secret <비밀번호>
 - e.g.) username admin secret cisco

password로 생성하면 사용자 비밀번호가 노출된다.
R1(config)#username admin password cisco
R1(config-line)# do sh run | sec admin
username admin password 0 cisco  <--  비밀번호 노출
R1(config)#no username admin    <-- 사용자 삭제
R1(config)#do sh run | sec admin

secret으로 생성하면 사용자 비밀번호가 암호화된다.
R1(config)#username admin secret cisco
R1(config)#do sh run | sec admin

## 실습.[LAB] 장비에 SSH 설정하기

보안상 원격접속은 Telnet은 사용하지 않고 SSH만 사용한다.


장비(라우터, 스위치)에 SSH를 설정하는 방법(명령어 7개):
1. enable 비밀번호 생성
enable 비밀번호를 생성한다.
형식: enable seret <비밀번호>
e.g.) enable secret cisco

2. 사용자 생성
장비에 접속하는 사용자를 생성한다.
형식: username <사용자명> secret <비밀번호>
e.g.) username admin secret cisco

3. 호스트명 생성
호스트명을 생성한다.
형식: hostname <호스트명>
e.g.) hostname R1

4. 도메인명을 생성한다.
도메인명을 생성한다.
호스트명을 생성하지 않고 도메인명을 생성하면 에러가 발생한다.
형식: ip domain-name <도메인명>
e.g.) ip domainname linuxmaster.net
hostname: R1
domainname: linuxmaster.net
도메인: R1.linuxmaster.net

5. RSA 공개키 생성
RSA 공개키 쌍을 생성한다.
형식: crypto key generate rsa
e.g.) crypto key generate rsa
How many bits in the modulus [512]: 2048  2048bit 를 선택한다.

6. SSH 버전 2 선택
SSHv1은 사용되지 않고 있으며 SSHv2 를 선택한다.

형식: ip ssh version 2
e.g.) ip ssh version 2

7. vty line에 원격 접속 설정
vty line에 로컬 사용자가 원격으로 접속할 수 있게 설정한다.
형식: line vty <start number> <end number>
e.g.)
line vty 0 4
 login local

기본값은 telnet, ssh 둘 다 접속이 가능하지만 SSH만 접속을 허용하고 Telnet 은 접속을 거부한다.
 transport input ssh

!R1
en
conf t
 enable secret cisco
 username admin secret cisco
 hostname R1
 ip domain-name mynetwork.com
 crypto key generate rsa
 <-- Key 길이 2048을 입력한다.
 ip ssh version 2
 line vty 0 4
 login local
 transport input ssh
! 

SSH 접속
  . ssh -l <사용자> <IP주소>
    - e.g.) 
      C:\>ssh -l admin 192.168.100.1  <-- 접속 가능
      C:\>telnet 192.168.100.1        <-- 접속 불가능 ( transport input ssh 설정했으므로 )
