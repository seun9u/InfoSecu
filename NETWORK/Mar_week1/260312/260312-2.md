## 실습.[LAB] 원격 접속(Telnet) 설정하기

### 1. 명령어 설명 (`line vty 0 4`)
* **전체 세션 수**: 0 ~ 15까지 총 16개 세션이 존재합니다.
* `line vty 0 4`는 0번부터 4번까지 **총 5개의 원격 접속 세션**을 허용한다는 의미입니다.
* 6번째 접속부터는 접속이 중단되며 아래와 같은 에러가 발생합니다.
  ```cmd
  C:\>telnet 192.168.100.1
  Trying 192.168.100.1 ...
  % Connection refused by remote host  
  ```

### 2. Telnet 기본 설정 및 접속 테스트

#### 📍 R1 기본 Telnet 설정
```ios
!R1
en
conf t
! enable password cisco
 enable secret cisco
 line vty 0 4
 password cisco
 end
wr 
```

#### 📍 접속 테스트 및 Enable 비밀번호 유무의 차이
```cmd
C:\>telnet 192.168.100.1
Trying 192.168.100.1 ...Open

User Access Verification
Password: 
R1>en
Password: 
R1#
```
* **Console 접속 시**: enable 비밀번호가 없어도 관리자 권한(`R1#`)으로 넘어갈 수 있습니다.
* **Telnet 접속 시**: enable 비밀번호가 설정되어 있지 않으면 관리자 권한으로 넘어갈 수 없습니다. (`% No password set.` 에러 발생)

---

### 3. 로컬 사용자(Username) 생성 및 적용
이전의 Telnet 방식은 사용자 이름 없이 비밀번호만 존재했습니다. 보안을 위해 장비에 직접 접속 사용자를 생성하여 적용할 수 있습니다.

* **형식**: `username <사용자명> secret <비밀번호>` (예: `username admin secret cisco`)

#### 📍 Password vs Secret 차이점
* **password 사용 시**: running-config에 비밀번호가 평문으로 노출됩니다.
  ```ios
  R1(config)# username admin password cisco
  R1(config)# do sh run | sec admin
  username admin password 0 cisco  <-- 비밀번호 노출
  R1(config)# no username admin    <-- 사용자 삭제 (초기화용)
  ```
* **secret 사용 시**: running-config에 비밀번호가 암호화되어 안전합니다.
  ```ios
  R1(config)# username admin secret cisco
  R1(config)# do sh run | sec admin
  username admin secret 5 $1$mERr$hx5rVt7rPNoS4wqbXKX7m0
  ```

#### 📍 생성한 사용자를 vty 라인에 적용 (`login local`)
```ios
R1(config)# line vty 0 4
R1(config-line)# login local
R1(config-line)# no password      ! 기존 단순 비밀번호 제거
R1(config-line)# do sh run | sec line vty
line vty 0 4
 login local
```

#### 📍 로컬 사용자 기반 접속 테스트
```cmd
C:\>telnet 192.168.100.1
Trying 192.168.100.1 ...Open

User Access Verification
Username: admin
Password: cisco
R1>
```

## 실습.[LAB] 장비에 SSH 설정하기

보안상 실무에서는 원격 접속 시 평문으로 통신하는 Telnet은 사용하지 않고, 암호화 통신을 하는 **SSH**만 사용합니다.


### 1. 장비에 SSH를 설정하는 방법 (명령어 7단계)

1. **Enable 비밀번호 생성**: `enable secret <비밀번호>`
2. **사용자 생성**: `username <사용자명> secret <비밀번호>`
3. **호스트명 생성**: `hostname <호스트명>` (기본 라우터 이름 대신 특정 이름 지정)
4. **도메인명 생성**: `ip domain-name <도메인명>`
   * *주의*: 호스트명과 도메인명이 모두 있어야 RSA 키를 생성할 수 있습니다. (예: `R1.mynetwork.com`)
5. **RSA 공개키 생성**: `crypto key generate rsa`
   * 명령 입력 후 묻는 Key 길이(modulus)에는 **2048**을 입력합니다.
6. **SSH 버전 2 선택**: `ip ssh version 2` (버전 1은 보안 취약점으로 사용하지 않음)
7. **vty line 원격 접속 설정**: 
   * `login local`: 로컬 생성 계정으로 로그인 허용
   * `transport input ssh`: 기본값은 telnet/ssh 둘 다 허용이지만, 이 명령어로 SSH 접속만 허용하고 Telnet은 거부하도록 설정합니다.

---

### 2. R1 SSH 전체 설정 스크립트 및 접속 확인

#### 📍 R1 SSH 설정 적용
```ios
!R1
en
conf t
 enable secret cisco
 username admin secret cisco
 hostname R1
 ip domain-name mynetwork.com
 crypto key generate rsa
 ! How many bits in the modulus [512]: 2048 입력
 ip ssh version 2
 line vty 0 4
 login local
 transport input ssh
 end
wr
```

#### 📍 PC에서 SSH 접속 테스트
```cmd
! SSH 접속 명령어: ssh -l <사용자명> <IP주소>
C:\>ssh -l admin 192.168.100.1      <-- 접속 성공
C:\>telnet 192.168.100.1            <-- 접속 실패 (transport input ssh 설정으로 차단됨)
```
