## 실습.[LAB] 라우터에서 DHCP Server 사용하기

IP 주소가 이미 설정이 된 상태에서 DHCP 서버를 설정하는 것이므로, 인터페이스 IP 주소 설정 부분은 생략합니다.

### 1. DHCP 설정 명령어 설명

* **`ip dhcp excluded-address`**
  * DHCP가 클라이언트에게 할당하지 않도록 특정 IP를 제외합니다.
  * 여러 개를 한 번에(범위 지정 등) 설정할 수 있습니다.
  * 예) `ip dhcp excluded-address 192.168.100.129 192.168.100.130`
* **`ip dhcp pool`**
  * DHCP 풀 이름을 생성합니다. 사용자가 원하는 이름으로 설정할 수 있습니다.
  * 예) `ip dhcp pool serverPool`
* **`network`**
  * 클라이언트에게 할당할 네트워크 대역과 서브넷 마스크를 설정합니다.
  * 예) `network 192.168.100.128 255.255.255.192`
* **`default-router`**
  * 클라이언트가 사용할 기본 게이트웨이를 설정합니다.
  * 예) `default-router 192.168.100.129`
* **`dns-server`**
  * 클라이언트가 사용할 DNS 서버를 설정합니다.
  * 예) `dns-server 192.168.100.132`

---

### 2. DHCP 확인 명령어 설명

`show ip dhcp ?` 명령어를 입력하면 관련 명령어 목록을 확인할 수 있습니다.

* **`binding`** (DHCP address bindings)
  * 어떤 디바이스(MAC 주소)가 어떤 IP 주소를 할당받았는지 확인할 때 사용합니다.
* **`pool`** (DHCP pools information)
  * DHCP 풀의 현재 상태 및 할당 정보를 확인할 때 사용합니다.
* **`conflict`** (DHCP address conflicts)
  * DHCP 주소 충돌을 확인할 때 사용합니다. (누군가 해당 대역의 IP를 고정 IP로 설정하여 사용 중일 때 충돌 발생)
* **`relay`** (Miscellaneous DHCP relay information)
  * 라우터가 DHCP 중계자(릴레이) 역할을 하는지 보는 정보입니다.
  * **※ DHCP Relay 동작 상황**: PC가 VLAN 10에 있고 DHCP 서버가 다른 네트워크에 있을 때, 브로드캐스트는 라우터를 넘어갈 수 없습니다. 그러므로 라우터가 브로드캐스트 형태의 DHCP 요청을 대신 받아서 유니캐스트로 서버에 전달해야 하며, 이때 인터페이스에 `ip helper-address` 명령어를 사용합니다.

**📍 추가 유용한 확인 명령어**
* `sh ip dhcp binding`: 현재 IP 할당 목록(바인딩) 확인
* `sh run | section dhcp`: running-config 내용 중 DHCP 관련 설정 부분만 필터링하여 확인
* `clear ip dhcp conflict *`: DHCP 충돌 이력 초기화

### 3. 실습 라우터 (R3) 설정 및 상태 확인

#### 📍 R3 DHCP 서버 설정 스크립트
```ios
!R3
en
conf t
! int fa0/0
! ip add 192.168.100.129 255.255.255.192
! no sh
 ip dhcp excluded-address 192.168.100.129 
 ip dhcp excluded-address 192.168.100.130 
 ip dhcp excluded-address 192.168.100.131 
 ip dhcp excluded-address 192.168.100.132 
 ip dhcp excluded-address 192.168.100.133
 ip dhcp pool serverPool
 network 192.168.100.128 255.255.255.192
 default-router 192.168.100.129
 dns-server 192.168.100.132
 end
wr
```
