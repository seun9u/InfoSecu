# 🌐 [실습.LAB] L3 스위치를 이용한 Inter-VLAN 설정

L3 스위치는 SVI(Switch Virtual Interface)를 생성하여 라우팅을 수행합니다. ROAS 방식과 달리 인터페이스에 직접 IP를 부여하는 것이 아니라, 가상의 VLAN 인터페이스를 활용하는 것이 특징입니다.

## 1. L3 스위치 Inter-VLAN 설정 원리
* **SVI 활용**: 각 VLAN에 해당하는 가상 인터페이스(SVI)를 만들고 IP 주소를 설정합니다.
* **라우팅 활성화**: `ip routing` 명령어가 반드시 설정되어야 합니다.
* **게이트웨이**: 각 PC는 L3 스위치의 해당 VLAN SVI 주소를 기본 게이트웨이로 설정합니다.



---

## 2. 장비별 상세 설정 스크립트

### 📍 SW1 설정 (Access & Trunk)
```ios
en
conf t
 hostname SW1
 no ip domain-lookup
 line con 0
  logging synchronous
 vlan 10
  name v10
 vlan 20 
  name v20
 int fa0/1
  switchport mode access
  switchport access vlan 10
  spanning-tree portfast
 int fa0/2
  switchport mode access
  switchport access vlan 20
  spanning-tree portfast
 int range fa0/23-24
  switchport mode trunk
 end
wr
```

### 📍 SW2 설정 (Access & Trunk)
```ios
en
conf t
 hostname SW2
 no ip domain-lookup
 line con 0
  logging synchronous
 vlan 10
  name v10
 vlan 20 
  name v20
 int fa0/1
  switchport mode access
  switchport access vlan 10
  spanning-tree portfast
 int fa0/2
  switchport mode access
  switchport access vlan 20
  spanning-tree portfast
 int fa0/24
  switchport mode trunk
 end
wr
```

### 📍 L3SW 설정 (SVI & Routing)
```ios
en
conf t
 hostname L3SW
 no ip domain-lookup
 line con 0
  logging synchronous
 vlan 10
  name v10
 vlan 20 
  name v20
  
! 라우팅 활성화 및 SVI 설정
 ip routing
 int vlan 10
  ip add 10.10.10.254 255.255.255.0
 int vlan 20
  ip add 10.10.20.254 255.255.255.0
 end
wr
```
