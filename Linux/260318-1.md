## 실습.[LAB] 리눅스 명령어 200개 사용하기 (Part 2)

### 4. 파일 내용 보기
**📍 전체 내용 보기**
* `cat`: 파일의 내용을 보는 가장 기본적인 명령어
  ```bash
  $ cat /etc/hosts
  $ cat /etc/passwd
  ```
* `tac`: 파일의 내용을 아래서부터 거꾸로(역순) 보여줍니다.
  ```bash
  $ tac list.txt
  ```

**📍 페이지 및 스크롤 단위 보기**
* `more`: 내용이 많은 경우 페이지 단위로 보여주며 끝에 도달하면 자동 종료됩니다. (`h`로 도움말 확인)
* `less`: 스크롤 가능한 형태로 보여주며 끝에 도달해도 자동 종료되지 않아 `q`를 눌러 종료합니다.

**📍 부분 내용 보기**
* `head`: 파일의 앞부분을 보여줍니다. (기본 10줄)
  ```bash
  $ head -n 3 /etc/passwd   # 앞에서부터 3줄
  ```
* `tail`: 파일의 뒷부분을 보여줍니다. (기본 10줄)
  * `tail -f`: 로그 파일 등을 실시간으로 모니터링할 때 사용합니다. (종료는 `Ctrl + C`)
  ```bash
  $ tail -n 3 /etc/passwd   # 뒤에서부터 3줄
  $ tail -f list.txt        # 실시간 모니터링
  ```

**📍 특수 출력 및 정렬**
* `nl`: 내용에 줄 번호를 붙여서 출력합니다. (`cat -n`과 동일)
* `wc`: 줄(`-l`), 단어(`-w`), 문자(`-c`) 수를 카운트합니다.
* `sort`: 파일 내용을 정렬해서 출력합니다.
* `uniq`: 중복되는 내용을 제거해서 출력합니다. (연속된 중복만 처리하므로 보통 `sort`와 함께 사용)
  ```bash
  $ uniq uniq.txt | sort
  ```

**📍 텍스트 열 및 변환 처리**
* `cut`: 특정 구분자를 기준으로 열을 잘라냅니다.
  ```bash
  $ cut -d: -f1 /etc/passwd   # ':' 구분자로 1번째 필드 추출
  ```
* `paste`: 여러 파일의 열을 나란히 붙여서 출력합니다.
* `tr`: 문자를 변환합니다.
  ```bash
  $ echo linux | tr a-z A-Z   # 대문자로 변환 (LINUX)
  ```
* `column -t`: 텍스트를 보기 좋게 열을 맞춰 출력합니다.
* `expand` / `unexpand`: 탭(Tab)을 공백으로, 공백을 탭으로 변환합니다.
* `strings`: 바이너리 파일(실행 파일, 악성코드 등)에서 읽을 수 있는 텍스트 문자열만 추출합니다.

**📍 바이너리/16진수 보기**
* `od`: 텍스트나 바이너리 파일을 문자/8진수/16진수로 덤프합니다. (`od -x`, `od -c`)
* `xxd`: 파일을 16진수로 보여주거나 다시 바이너리로 복원(`-r`)합니다. (`vim-common` 패키지 필요)

### 5. 텍스트 검색 및 처리
**📍 문자열 검색 (`grep`)**
* `grep`: 텍스트 파일에서 특정 문자열을 검색합니다.
  ```bash
  $ grep root /etc/passwd
  $ grep ^root /etc/passwd       # root로 시작하는 줄 검색
  ```
* `grep -i`: 대소문자를 무시하고 검색합니다.
* `grep -r`: 하위 디렉터리까지 재귀적으로 검색합니다.
  ```bash
  $ grep -r root /etc/  2> /dev/null  # 에러(권한 거부 등)는 휴지통(/dev/null)으로 보내 깔끔하게 출력
  ```
* `egrep` (`grep -E`): 확장 정규식을 사용하여 다중 문자열 등을 검색합니다.
  ```bash
  $ egrep 'root|linuxadmin' /etc/passwd
  ```
* `fgrep` (`grep -F`): 정규식을 무시하고 특수문자 등을 있는 그대로 검색합니다.

**📍 기타 텍스트/파일 검색 도구**
* `sed`: 텍스트 치환 및 편집 도구 (Stream Editor)
* `awk`: 열 기반 데이터 처리 도구
* `find`: 시스템에서 조건(이름, 크기, 시간 등)에 맞는 파일을 직접 검색합니다.
  ```bash
  $ find /etc -name passwd 2> /dev/null
  ```
* `locate` / `updatedb`: 자체 데이터베이스를 기반으로 파일을 빠르게 검색합니다. (사전에 `updatedb`로 DB 갱신 필요)

### 6. 명령어 경로 및 종류 확인
* `which`: 실행 파일이나 alias의 경로를 출력합니다.
  ```bash
  $ which ls
  ```
* `whereis`: 명령어와 관련된 바이너리, 소스코드, 매뉴얼 파일의 위치를 모두 출력합니다.
* `type`: 명령어의 종류(alias, 내부 명령어, 외부 명령어, 함수)를 확인합니다.
  ```bash
  $ type ls     # alias 여부 등 출력
  $ type rm     # 해시된 외부 경로 출력
  ```
* `hash`: 사용자가 세션 내에서 한 번이라도 실행했던 외부 명령어의 경로를 캐싱해둔 해시 테이블을 확인하거나 지웁니다(`-r`).
