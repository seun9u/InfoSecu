## **1. 실습 [LAB] CentOS 7 서비스 설정하기**

### **1) CentOS 7 다운로드 및 준비**
* 직접 설치하려면 시간이 많이 걸리므로 이미 설치된 배포판을 다운로드하여 세팅합니다.
* **다운로드 링크**: [Google Drive 링크](https://drive.google.com/file/d/1oOEX7HTYdR36pIPW0ybJsejkMEG5BDAR/view?usp=drive_link)
* **참고 영상**: [YouTube 링크](https://youtu.be/AMoYeSdYj5Y)
* **CentOS 구버전 아카이브(참고용)**: https://vault.centos.org/
  * CentOS 7 ISO 경로: https://vault.centos.org/7.9.2009/isos/x86_64/

### **2) CentOS 7 가상머신(VM) 세팅**
1. 다운로드가 완료되면 `내문서 > Virtual Machines` 디렉터리로 이동시킨 후 압축을 해제합니다.
2. 폴더명을 `CentOS7`에서 `CentOS7-WEBBOAN`으로 변경합니다.
3. `CentOS7-WEBBOAN` 폴더 안의 `CentOS7.vmx` 파일을 실행합니다.
4. 가상머신 프로그램 목록에서 가상머신의 이름을 `CentOS7`에서 `CentOS7-WEBBOAN`으로 변경합니다.
5. 메모리(RAM)를 `1G`에서 `2G`로 증설한 후 부팅을 진행합니다.
6. 안내창이 나타나면 **[I Copied It]**을 클릭하고 부팅을 완료합니다.

### **3) 로그인 및 네트워크 설정 (IP 수동 할당)**
* **로그인 정보**: 관리자(`root`) / 비밀번호(`1`) 로 로그인합니다.
* **목표 IP 주소**: `192.168.100.10/24`

```bash
# 네트워크 설정 툴 실행
[root@localhost ~]# nmtui
```

* **nmtui 설정 순서**:
  1. `연결 편집` 선택 > `ens33` 선택 후 `<편집...>` 누름
  2. `IPv4 설정`: `<수동>` 으로 변경
  3. `주소`: `192.168.100.10/24`
  4. `게이트웨이`: `192.168.100.2`
  5. `DNS 서버`: `168.126.63.1`, `168.126.63.2`
  6. `<OK>` 선택 후 `<뒤로>` 이동
  7. `시스템의 호스트 이름 설정` 선택
  8. `호스트 이름`: `victim.linuxmaster.net`
  9. `<OK>` 선택 후 `종료`

```bash
# 호스트 파일(hosts) 수정
[root@localhost ~]# vi /etc/hosts
```
```text
127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
192.168.100.10 victim victim.linuxmaster.net
```
```bash
# 설정 적용을 위해 재부팅
[root@localhost ~]# reboot
```

## **2. 실습 [LAB] CentOS 7 업데이트 설정하기**

### **1) 패키지 설치 오류 현상 확인**
* CentOS 7은 **2024년 6월 30일 자로 수명(EOL)이 만료**되었습니다.
* 이 때문에 기본 패키지 저장소 서버가 닫혀 있어 패키지 설치 및 업데이트 시 아래와 같은 오류가 발생합니다.

```bash
[root@victim ~]# which mc
/usr/bin/which: no mc in (/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/root/bin)

[root@victim ~]# yum -y install mc
Loaded plugins: fastestmirror
Determining fastest mirrors
Could not retrieve mirrorlist [http://mirrorlist.centos.org/?release=7&arch=x86_64&repo=os&infra=stock](http://mirrorlist.centos.org/?release=7&arch=x86_64&repo=os&infra=stock) error was
14: curl#6 - "Could not resolve host: mirrorlist.centos.org; 알 수 없는 오류"

 One of the configured repositories failed (Unknown),
 and yum doesn't have enough cached data to continue. At this point the only
 safe thing yum can do is fail. There are a few ways to work "fix" this:
     # ...(중략: yum 해결 방법에 대한 안내문)...
 Cannot find a valid baseurl for repo: base/7/x86_64
```

### **2) 패키지 저장소(Repository) 주소 변경 해결법**
* 오류를 해결하려면 `/etc/yum.repos.d/CentOS-Base.repo` 파일을 열어 만료된 `mirrorlist` 주석 처리하고, 예전 패키지를 보관하는 `vault.centos.org` 로 `baseurl`을 수정해야 합니다.

```bash
[root@victim ~]# vi /etc/yum.repos.d/CentOS-Base.repo
```
```ini
# CentOS-Base.repo
# (상단 주석 내용 생략)

[base]
name=CentOS-$releasever - Base
#mirrorlist=[http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=os&infra=$infra](http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=os&infra=$infra)
#baseurl=[http://mirror.centos.org/centos/$releasever/os/$basearch/](http://mirror.centos.org/centos/$releasever/os/$basearch/)
baseurl=[http://vault.centos.org/7.9.2009/os/$basearch/](http://vault.centos.org/7.9.2009/os/$basearch/)     <-- 주소 변경 부분
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7

#released updates
[updates]
name=CentOS-$releasever - Updates
#mirrorlist=[http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=updates&infra=$infra](http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=updates&infra=$infra)
#baseurl=[http://mirror.centos.org/centos/$releasever/updates/$basearch/](http://mirror.centos.org/centos/$releasever/updates/$basearch/)
baseurl=[http://vault.centos.org/7.9.2009/os/$basearch/](http://vault.centos.org/7.9.2009/os/$basearch/)     <-- 주소 변경 부분
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7

#additional packages that may be useful
[extras]
name=CentOS-$releasever - Extras
#mirrorlist=[http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=extras&infra=$infra](http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=extras&infra=$infra)
#baseurl=[http://mirror.centos.org/centos/$releasever/extras/$basearch/](http://mirror.centos.org/centos/$releasever/extras/$basearch/)
baseurl=[http://vault.centos.org/7.9.2009/os/$basearch/](http://vault.centos.org/7.9.2009/os/$basearch/)     <-- 주소 변경 부분
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7

#additional packages that extend functionality of existing packages
[centosplus]
name=CentOS-$releasever - Plus
#mirrorlist=[http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=centosplus&infra=$infra](http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=centosplus&infra=$infra)
#baseurl=[http://mirror.centos.org/centos/$releasever/centosplus/$basearch/](http://mirror.centos.org/centos/$releasever/centosplus/$basearch/)
baseurl=[http://vault.centos.org/7.9.2009/os/$basearch/](http://vault.centos.org/7.9.2009/os/$basearch/)     <-- 주소 변경 부분
gpgcheck=1
enabled=0
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
```
