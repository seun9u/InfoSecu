## **실습. [LAB] Tomcat / JSP 환경 구성하기 1**

### **Tomcat**
  . Java 기반의 JSP(Java Servlet Page) 환경의 자바 언어로 웹 애플리케이션을 작성할 수 있는 무료 웹 애플리케이션 서버이다.
  . APM 환경, 방화벽이 구축된 환경에서 Tomcat에 JSP를 사용할 수 있게 설정한다.

---

### **1. 패키지 설치**
tomcat 관련 패키지를 설치한다.

```bash
[root@victim ~]# yum -y install java-1.8.0-openjdk java-1.8.0-openjdk-devel \
tomcat tomcat-webapps tomcat-admin-webapps
```

### **2. tomcat 시작**
tomcat 서비스를 활성화하고 tomcat을 실행한다. CentOS 7에서는 tomcat을 실행하면 기본 포트 3개가(8080, 8009, 8005) 오픈된다.
  . **8080 포트**: 기본으로 설정되어 있는 웹서비스 포트
  . **8005 포트**: HTTP 프로토콜을 처리하기 위한 내부 접속용 포트
  . **8009 포트**: `mod_jk.so` 를 이용해서 아파치 웹서버와 통신하기 위한 포트

```bash
[root@victim ~]# systemctl enable --now tomcat.service
[root@victim ~]# firewall-cmd --permanent --add-port=8080/tcp
[root@victim ~]# firewall-cmd --reload

[root@victim ~]# firewall-cmd --permanent --list-ports
8080/tcp
[root@victim ~]# firewall-cmd --permanent --list-services
http https ssh
```

* `--list-services`, `--list-ports` 를 동시에 확인할 수 있는 옵션이 `--list-all` 이다.
```bash
[root@victim ~]# firewall-cmd --list-all
public (active)
  target: default
  icmp-block-inversion: no
  interfaces: ens33
  sources:
  services: http https ssh
  ports: 8080/tcp
  protocols:
  masquerade: no
  forward-ports:
  source-ports:
  icmp-blocks:
  rich rules:
```

* http://192.168.100.10:8080/

### **4. 설정파일 수정**
`/etc/tomcat/tomcat-users.xml` 파일의 내용에서 `admin-gui`를 수정한다. 이 부분은 WEB Application 을 Deploy(배포) 하기 위해서 필요하다.

**`/etc/tomcat/tomcat-users.xml` 파일의 역할**
  . Tomcat 관리자 로그인 계정 생성
  . Manager App / Host Manager App 접근 권한 부여
  . 사용자별 role 지정
  . 파일에 들어가는 정보
    - 사용자 이름(username)
    - 비밀번호(password)
    - 역할(role)
      . `<role rolename="admin-gui"/>`
        - admin 역할(role) 정의한다.
      . `<user name="admin" password="adminadmin" roles="admin,manager ... />`
        - Tomcat 관리자 계정 admin 을 만들고 여러 관리 권한(role)을 한꺼번에 부여한 상태이다.

`/etc/tomcat/tomcat-users.xml` 파일을 열어서 아래 라인의 주석을 제거한다. (43번, 50번 라인: 주석제거)
```bash
[root@victim ~]# vi /etc/tomcat/tomcat-users.xml
```
```xml
43 <role rolename="admin-gui"/>
50 <user name="admin" password="adminadmin" roles="admin,manager,admin-gui,admin-script,manager-gui,manager-script,manager-jmx,manager-status" />
```

### **5. JSP 파일 생성**
웹 기본 경로로 접속해서 `hello.jsp` 파일을 생성한다.
* `/usr/share/tomcat/webapps/ROOT` (`~tomcat/webapps/ROOT/`): JSP 웹 페이지 경로
* http://192.168.100.10:8080/ 페이지에 접속했을 때 보여지는 경로이다.

```bash
[root@victim ~]# cd ~tomcat/webapps/ROOT/

[root@victim ROOT]# pwd -P
/var/lib/tomcat/webapps/ROOT

[root@victim ROOT]# pwd -L
/usr/share/tomcat/webapps/ROOT
```

**운영체제별 vi 복사/붙여넣기 팁**
* **CentOS 7**
  . 복사/붙여넣기: `vi hello.jsp` > `:set noai` > `:set paste` > `i` > 복사 > 붙여넣기
* **Rocky Linux 8, 9**
  . 복사/붙여넣기: 필요없다.

```bash
[root@victim ROOT]# vi hello.jsp
```
```jsp
<%@ page contentType="text/html; charset=utf-8" %>
<%! String str = "Hello JSP!"; %>
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>::: <%=str%> :::</title>
</head>
<body>
    <center>
    <h1> JSP 세계에 오신 것을 환영합니다.</h1>
    <P>
<%
      int i = 1;
      while(i <= 5)
      {
         out.println(i + ".");
         out.println(str);
         out.println("<br>");
         i++;
      }
%>
    </center>
</body>
</html>
```
```bash
[root@victim ROOT]# cd
```
