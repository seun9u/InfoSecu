## **1. 파일 시스템 구조 및 그룹 비밀번호 설정**

### **/etc/group 과 /etc/gshadow 의 차이**
사용자를 생성하면 관련 정보가 저장됩니다.
* **`/etc/group` 필드 (그룹명:그룹비밀번호:GID:그룹멤버)**
  * 현대 OS에서는 보안상 비밀번호 필드에 단순 `x`가 들어가며, 실제 암호는 `/etc/gshadow`에 저장됩니다.
* **`/etc/gshadow` 필드 (그룹명:그룹비밀번호:그룹관리자:그룹멤버)**
  * 그룹 비밀번호에 `!` 가 있으면 그룹에 비밀번호가 없는 것입니다.
  * 그룹 관리자나 멤버에 값이 없으면, 기본 생성된 사용자 외에는 권한/멤버가 없는 것입니다.

### **gpasswd: 그룹 비밀번호 변경**
* 그룹의 비밀번호를 설정하거나 멤버/관리자를 관리합니다.
* `/etc/gshadow` 파일은 일반 유저가 접근할 수 없으므로, root가 아닌 일반 관리자가 사용하려면 `sudo`가 필요합니다.
  * *권한 확인: `----------. 1 root root 417 /etc/gshadow`*

```bash
# 실습을 위한 사용자 2명 생성
$ sudo useradd user1
$ sudo useradd user2

$ tail -n 3 /etc/group
linuxadmin:x:1000:
user1:x:1001:
user2:x:1002:

$ sudo tail -n 3 /etc/gshadow
linuxadmin:!::
user1:!::
user2:!::

# user1 그룹에 비밀번호 설정
$ LANG=en_US.utf8
$ sudo gpasswd user1
Changing the password for group user1
New Password:
Re-enter new password:

# 설정된 비밀번호 해시 확인
$ sudo grep user1 /etc/gshadow
user1:$6$5TjmPJ3vQ2kXvbRY$FE0OlFikQln4SQJUJQm26X6SnFc/dMcx ... ::

# 비밀번호를 이용해 다른 그룹으로 전환 (newgrp)
$ echo $SHLVL
1
$ id
uid=1000(linuxadmin) gid=1000(linuxadmin) groups=1000(linuxadmin),10(wheel) ...

$ newgrp user1
Password:  <-- user1 그룹에 설정한 비밀번호 입력

$ echo $SHLVL
2
$ id
uid=1000(linuxadmin) gid=1001(user1) groups=1001(user1),10(wheel),1000(linuxadmin) ...

# 변경된 기본 그룹(user1)으로 파일 생성
$ touch file3.txt
$ ll file3.txt
-rw-r--r--. 1 linuxadmin user1 0 Mar 24 11:29 file3.txt
```

## **2. 그룹 멤버 및 관리자 지정 (`gpasswd` 옵션 활용)**

### **그룹 멤버 추가 (`-a`, `-M`)**
* `gpasswd -a 사용자 그룹명` : 특정 사용자를 그룹 멤버로 1명씩 추가합니다.
* `gpasswd -M 사용자1,사용자2 그룹명` : 그룹 멤버 목록 전체를 한 번에 덮어쓰기로 설정합니다.
* 그룹에 포함되면 `/etc/group`, `/etc/gshadow` 두 파일 끝에 멤버 이름이 저장됩니다. (여러 명일 경우 `,`로 구분)

```bash
# 추가 실습용 사용자 생성 및 확인
$ sudo useradd user3
$ sudo useradd user4
$ sudo useradd user5

# linuxadmin을 user1 그룹에 추가 (-a)
$ sudo gpasswd -a linuxadmin user1
$ sudo grep ^user1 /etc/{group,gshadow}
/etc/group:user1:x:1001:linuxadmin
/etc/gshadow:user1:$6$5TjmPJ3vQ2kXvbRY$... ::linuxadmin

# 여러 명을 일괄 지정 (-M)
$ sudo gpasswd -M user1,user2,user3,user4 user5
$ sudo grep ^user5 /etc/{group,gshadow}
/etc/group:user5:x:1005:user1,user2,user3,user4
/etc/gshadow:user5:!:linuxadmin,user1,user2:user1,user2,user3,user4

# -M 옵션으로 빈 값('')을 주면 멤버 초기화
$ sudo gpasswd -M '' user3
```

### **그룹 멤버 삭제 (`-d`)**
* `gpasswd -d 사용자 그룹명` : 그룹에서 특정 멤버를 제거합니다.

```bash
# user2 사용자를 user1 그룹에서 제거
$ sudo gpasswd -d user2 user1
$ sudo grep ^user1 /etc/{group,gshadow}
/etc/group:user1:x:1001:linuxadmin,user3
```

### **그룹 관리자 지정 (`-A`)**
* 그룹의 관리자는 `/etc/group`에는 없고 `/etc/gshadow`의 3번째 필드에만 존재합니다.
* 그룹 관리자로 설정되면 (슈퍼유저가 아니더라도) 해당 그룹의 멤버를 추가/삭제할 수 있는 권한이 생깁니다.
* `gpasswd -A 관리자1,관리자2 그룹명` : 관리자를 지정합니다. (멤버로 자동 포함되지는 않으므로 별도 추가 필요)

```bash
# user5 그룹에 관리자 3명 지정
$ sudo gpasswd -A linuxadmin,user1,user2 user5
$ sudo grep user5 /etc/{group,gshadow}
/etc/group:user5:x:1005:
/etc/gshadow:user5:!:linuxadmin,user1,user2:  <-- 관리자 지정됨
```

### **💡 일반 유저의 그룹 관리자 권한 실습**
관리자 그룹에 포함되어 있으면 `sudo` 없이도 일반 유저가 멤버를 추가할 수 있습니다.

```bash
$ id -un
linuxadmin

# linuxadmin은 user5의 관리자이므로 멤버 등록 가능
$ gpasswd -a user3 user5
Adding user user3 to group user5

# 하지만 linuxadmin이 user3의 관리자가 아니면 멤버 등록 불가
$ gpasswd -a user1 user3
gpasswd: Permission denied.

# 이 경우 root 권한(sudo)으로만 등록 가능
$ sudo gpasswd -a user1 user3
```

## **3. 사용자 삭제 시 주의사항**
특정 사용자가 다른 그룹의 멤버로 포함되어 있으면, 사용자는 삭제되지만 **해당 사용자의 이름으로 된 기본 그룹은 삭제되지 않고 남습니다.**

```bash
# UID 1001 이상 사용자 삭제 스크립트 실행
$ sudo delete-users-uid1001.sh
[sudo] password for linuxadmin:
userdel: group user1 not removed because it has other members.

# 사용자는 지워졌지만, 그룹에 linuxadmin이 멤버로 있어 user1 그룹이 남음
$ grep user1 /etc/passwd
(결과 없음)
$ grep user1 /etc/group
user1:x:1001:linuxadmin

# 남은 그룹은 수동으로 삭제 필요
$ sudo groupdel user1
$ grep user1 /etc/group
(결과 없음)
```
