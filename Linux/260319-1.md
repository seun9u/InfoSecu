## **1. 실습 [LAB] C 소스 패치파일 만들기**
* 원본 소스와 수정된 소스를 비교하여 패치 파일을 만들고 적용합니다. (참고: https://gist.github.com/ThisIsMissEm/642175)

### **1.1 소스 코드 생성**
```bash
$ vi hello_old.c
```
```c
#include <stdio.h>

int main() {
    printf("Hello\n");
    return 0;
}
```

```bash
$ vi hello_new.c
```
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

### **1.2 패치 파일 만들기**
* `-u` : unified format 형식으로 출력. 변경 전후 내용과 주변 문맥(context)을 같이 묶어서 보기 좋게 출력합니다.
* `diff`를 옵션 없이 사용하면 변경된 내용만 간략히 보여줍니다.

```bash
$diff -u hello_old.c hello_new.c > myprogram.patch$ cat myprogram.patch
--- hello_old.c 2026-03-19 11:09:33.578008674 +0900
+++ hello_new.c 2026-03-19 11:10:18.932834269 +0900
@@ -1,6 +1,6 @@
 #include <stdio.h>

 int main() {
-    printf("Hello\n");
+    printf("Hello, World!\n");
     return 0;
 }
```
**[패치 파일 기호 의미]**
* `---`: 원본 파일
* `+++`: 수정(새) 파일
* `@@`: 변경 위치 정보 (원본/새 파일의 줄 범위)
* `-`: 원본에서 제거되거나 변경되기 전의 줄
* `+`: 새 파일에 추가되거나 변경된 후의 줄
* ` `(공백): 바뀌지 않은 문맥 줄

### **1.3 패치 적용 (`patch`)**
* `patch` 명령어를 사용하기 위해 패키지를 설치합니다.
* `-p0` : 패치 파일 안에 있는 파일 경로(이름)의 앞부분을 잘라내지 않고 그대로 현재 위치에서 적용하라는 의미입니다.

```bash
$sudo dnf -y install gcc patch$ patch -p0 < myprogram.patch

$ cat hello_old.c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

$ diff hello_old.c hello_new.c
# <-- 두 파일이 동일해졌으므로 아무것도 출력되지 않습니다.
```

## **2. `cmp` : 바이트 비교**
* 파일을 바이트 단위로 비교할 때 사용합니다.

```bash
$echo Hello > file1.txt$ echo Hello > file2.txt
$echo Hello. > file3.txt$ cmp file1.txt file2.txt
$ cmp file1.txt file3.txt
file1.txt file3.txt differ: char 6, line 1
```

## **3. 편집기 및 출력 명령어**

### **`vi` / `vim` / `nano` / `view`**
* **`vi`**: 리눅스에서 가장 많이 사용하는 강력한 편집기. Rocky Linux 9부터는 `/usr/bin/vim`을 실행하는 셸 스크립트로 동작합니다.
* **`vim`**: 향상된 vi. `sudo dnf -y install vim`
* **`nano`**: 입문자가 사용하기 쉬운 편집기. (`Ctrl+X` 로 종료/저장)
* **`view`**: 읽기 전용 모드(`-R` 옵션)로 열리는 vi.

```bash
$sudo dnf -y install vim nano$ nano nano.txt      # 편집 후 Ctrl+X > y > Enter 로 저장
$view DIR_COLORS    # 읽기 전용으로 파일 열기$ vi -R DIR_COLORS   # view와 동일한 효과
```

### **`tee` : 화면 + 파일 동시 출력**
* 표준 출력을 화면에 보여주는 동시에 파일로 저장합니다.

```bash
$ echo Hello | tee hello.txt
Hello
$ cat hello.txt
Hello

$ df | tee df.txt
```

### **`script` : 터미널 기록 저장**
* 현재 터미널에서 입력하고 출력되는 모든 내용을 녹화하듯 파일에 기록합니다. `exit`으로 종료합니다.

```bash
$ script session.log
Script started, output log file is 'session.log'.
$ echo $SHLVL
2
$ pwd
$ id
$ ls
$ exit
Script done on 2026-03-19 12:43:51+09:00 [COMMAND_EXIT_CODE="0"]

$ cat session.log  # vi로 보면 제어문자가 깨져 보이므로 cat으로 확인 권장
```
