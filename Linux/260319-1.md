## **1. 실습 [LAB] C 소스 패치파일 만들기**
* 원본 소스와 수정된 소스를 비교하여 패치 파일을 만들고 적용합니다. (참고: https://gist.github.com/ThisIsMissEm/642175)

### **1.1 소스 코드 생성**
```bash
$ vi hello_old.c
```
```c
#include <stdio.h>

int main() {
    printf("Hello\n");
    return 0;
}
```

```bash
$ vi hello_new.c
```
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

### **1.2 패치 파일 만들기**
* `-u` : unified format 형식으로 출력하라는 의미입니다. 변경된 내용만 보여주는 것이 아니고 변경 전후 내용을 함께 주변 몇 줄의 문맥(context)과 같이 보기 좋게 묶어서 출력하는 형식입니다.
* `diff`를 옵션 없이 사용하면 변경된 내용만 보여줍니다.

```bash
$diff -u hello_old.c hello_new.c > myprogram.patch$ cat myprogram.patch
--- hello_old.c 2026-03-19 11:09:33.578008674 +0900
+++ hello_new.c 2026-03-19 11:10:18.932834269 +0900
@@ -1,6 +1,6 @@
 #include <stdio.h>

 int main() {
-    printf("Hello\n");
+    printf("Hello, World!\n");
     return 0;
 }
```
**[패치 파일 기호 의미]**
* `---`: 원본 파일 (뒤의 날짜/시간은 원본 파일의 시간 정보)
* `+++`: 수정 파일 (새 파일, 뒤의 날짜/시간은 수정 파일의 시간 정보)
* `@@`: 변경 위치 정보 (원본 파일과 새 파일에서 변경이 발생한 줄 범위)
* `-`: 원본에서 삭제된 줄 (변경 전 내용)
* `+`: 새 파일에 추가된 줄 (변경 후 내용)
* ` `(공백 한 칸으로 시작): 바뀌지 않은 문맥 줄

### **1.3 패치 적용**
* `path` 명령어를 사용하기 위해서 patch 패키지를 설치합니다.
* `-p0` 은 패치 파일 안에 있는 파일 경로를 그대로 사용하라는 의미입니다. 파일 이름 앞부분을 잘라내지 않고 그대로 현재 위치에서 적용하라는 뜻입니다.

```bash
$sudo dnf -y install gcc patch$ patch -p0 < myprogram.patch

$ cat hello_old.c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

$ cat hello_new.c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

$ diff hello_old.c hello_new.c
# <-- 아무것도 나오지 않는다.
```

## **2. `cmp` : 바이트 비교**
* 파일을 비교할 때 사용합니다.

```bash
$echo Hello > file1.txt$ echo Hello > file2.txt
$echo Hello. > file3.txt$ cmp file1.txt file2.txt
$ cmp file1.txt file3.txt
```

## **3. 편집기 및 출력 명령어**

### **`vi` / `vim` / `nano` / `view` 및 기타 편집기**
* **`vi`**: vi 편집기 실행 (`/usr/bin/vi`). 리눅스에서 많이 사용하는 편집기.
  * 장점: 기능이 다양하고 강력해서 다른 편집기를 못 쓴다.
  * 단점: 기능이 너무 많아서 입문자는 어렵다.
  * Rocky Linux 9 이전: `/usr/bin/vi`, `/usr/bin/vim` 이 실행 파일.
  * Rocky Linux 9 버전: `/usr/bin/vi` 는 셸 스크립트이고, `/usr/bin/vim` 이 실행 파일입니다.
* **`vim`**: 향상된 vi (`/usr/bin/vim`).
* **`nano`**: 쉬운 편집기. 리눅스 입문자들이 사용하는 편집기로 vi 보다 많이 쉽습니다.
* **`view`**: 읽기 전용 vim. Rocky Linux 9 배포판에서 `vi -R`, `vim -R` 옵션을 사용하는 셸 스크립트입니다.
* **`ed`**: 줄 단위 편집기
* **`ex`**: vi 기반 편집기
* **`dos2unix`**: 윈도우 개행 변환
* **`unix2dos`**: 도스 개행 변환

```bash
$sudo dnf -y install vim nano$ nano nano.txt      # 편집 후 Ctrl+X > y > Enter 로 저장
$view DIR_COLORS    # 읽기 전용으로 파일 열기$ vi -R DIR_COLORS   # view와 동일한 효과
```

### **`tee` : 화면+파일 저장**
* 가는 길이 2군데입니다. (화면 출력과 파일 저장을 동시에 수행)

```bash
$ echo Hello | tee hello.txt
Hello
$ cat hello.txt
Hello

$df > df.txt$ cat df.txt

$ df | tee df.txt
```

### **`script` : 터미널 기록 저장**
* 현재 터미널에서 입력하고 출력되는 내용을 파일에 기록하는 명령어입니다.
* `script 파일명`으로 시작하고 `exit`으로 종료하면 작업한 내용을 통째로 녹화하듯 기록합니다. 명령을 실행하면 새로운 셸이 하나 열리고 그 안에서 동작합니다.

```bash
$ echo $SHLVL
1

$ script session.log
Script started, output log file is 'session.log'.
$ echo $SHLVL
2

$ pwd
$ id
$ ls
$ exit
Script done on 2026-03-19 12:43:51+09:00 [COMMAND_EXIT_CODE="0"]

# session.log 파일에는 명령어와 실행결과가 들어가 있고 vi로 보면 깨져 있기 때문에 cat으로 확인합니다.
$ cat session.log
```
