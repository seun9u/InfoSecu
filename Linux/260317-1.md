## 실습.[LAB] 명령어 200개 사용하기

**📍 명령어 종류**
* **alias 명령어**: 사용자가 지정한 별칭 명령어
* **내부 명령어**: 쉘(Shell) 자체에 내장된 명령어
* **외부 명령어**: 별도의 실행 파일로 존재하는 명령어

---

### 1. 실습 네트워크 및 기본 접속 환경

**📍 IP 및 서브넷 정보**
* **네트워크**: `192.168.100.0/24` (Subnet Mask: 255.255.255.0 / `11111111.11111111.11111111.00000000`)
* **네트워크 주소**: 192.168.100.0
* **브로드캐스트 주소**: 192.168.100.255
* **가용 IP 주소**: 192.168.100.1 ~ 192.168.100.254
* **Host OS IP**: 192.168.100.1

**📍 기본 접속 및 제어 명령어**
* `ssh -l linuxadmin 192.168.100.3`: 192.168.100.3 서버로 원격 접속하기
* `nmtui`: 네트워크 설정(Network Manager Text User Interface)
* `reboot`: 시스템 재부팅

---

### 2. 기본 이동 및 목록 확인 명령어

**📍 화면 제어 및 환경 변수**
* `clear`: 화면 지우기 (단축키: `Ctrl + L`)
* `pwd`: 현재 작업 중인 디렉터리 위치 확인
* `echo $LANG`: 언어셋 환경변수에 설정된 값 보기
* `LANG=en_US.UTF-8`: LANG 환경변수를 영문 값으로 변경

**📍 디렉터리 목록 보기 (`ls`)**
* `ls`: 파일 목록 보기
* `ls -l`: 파일 자세히 보기
* `ls -a`: 숨김 파일까지 포함해서 보기
* `ls -alh`: 용량 단위(KB, MB 등) 보기 (숨김 파일 포함)
* `ls -alt`: 시간순으로 보기 (숨김 파일 포함)
* `ls /`: 최상위 디렉터리(`/`) 목록 보기

**📍 경로 이동 (`cd`)**
* `cd`: 기본 디렉터리로
* `cd /etc`: /etc 디렉터리로 이동
* `cd ..` : 상위로 이동
* `cd /home` : /home 디렉터리로 이동
* `cd / `: 최상위 루트 디렉터리로 이동
* `cd `: 홈으로 이동
* `cd ~` : 홈으로 이동
* `cd -` : 이전 디렉터리로 이동
