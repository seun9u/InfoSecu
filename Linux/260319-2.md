## **1. 사용자 및 로그인 정보 확인**

### **`who` / `w` / `users` / `logname`**
* **`who`**: 시스템에 로그인한 사용자 확인 (`/var/run/utmp` 참조)
* **`w`**: 로그인한 사용자의 상세 상태 및 시스템 부하(load average) 출력
* **`users`**: 로그인한 사용자 이름 목록만 간략히 출력
* **`logname`**: 현재 셸에 처음 로그인한 사용자의 이름 출력

```bash
$ who
linuxadmin pts/0        2026-03-19 14:02 (192.168.100.1)

$ w
 14:17:32 up 14 min,  1 user,  load average: 0.00, 0.00, 0.00
USER     TTY        LOGIN@   IDLE   JCPU   PCPU WHAT
linuxadm pts/0      14:02    1.00s  0.05s  0.00s w

$ users
linuxadmin user1
$ logname
linuxadmin
```

### **`last` / `lastb` : 로그인 성공/실패 기록**
* **`last`**: 정상 로그인 및 재부팅 기록 확인 (`/var/log/wtmp` 참조)
* **`lastb`**: 로그인 실패 기록 확인 (`/var/log/btmp` 참조, 보안 점검에 자주 사용, root 권한 필요)

```bash
$ last
user1    pts/1        192.168.100.1    Thu Mar 19 14:30   still logged in  
linuxadm pts/1        192.168.100.1    Thu Mar 19 14:03 - 14:10  (00:07)
reboot   system boot  5.14.0-611.5.1.e Thu Mar 19 14:02   still running

$ sudo lastb
testuser ssh:notty    192.168.100.3    Thu Mar 19 15:17 - 15:17  (00:00)
```
*(참고: `/var/log/btmp` 파일의 초기화는 `sudo cp /dev/null /var/log/btmp` 명령어를 사용합니다.)*

## **2. 사용자 및 그룹 관리**

### **`useradd` / `usermod` / `userdel`**
* 사용자 생성 시 `/etc/passwd`, `/etc/shadow`, `/etc/group`, `/etc/gshadow` 에 정보가 추가되며, 홈 디렉터리와 메일함이 생성됩니다.
* **비밀번호 파일 정보 권한**: `passwd`, `group`은 일반 유저 읽기 가능 / `shadow`, `gshadow`는 접근 불가

```bash
$ sudo useradd user1
$ sudo passwd user1

# 사용자 셸 정보 수정 (vipw를 통한 안전한 편집 권장)
$sudo usermod -s /bin/sh user3$ sudo vipw  # vi /etc/passwd 대신 사용

# 사용자 삭제 (-r: 홈 디렉터리와 메일 스풀까지 함께 삭제)
$ sudo userdel -r user1
```

### **`groupadd` / `groupmod` / `groupdel`**
* 그룹 ID(GID)보다 이름으로 주로 접근하므로 그룹명이 중요합니다.

```bash
$ sudo groupadd project1
$ sudo groupadd project3

# 그룹 GID 및 이름 변경
$sudo groupmod -g 1005 project3   # GID를 1005로 변경$ sudo groupmod -n prj3 project3   # 이름을 prj3로 변경

# 그룹 삭제
$ sudo groupdel project1
```

## **3. 계정 및 패스워드 만료 설정 (`chage`)**
사용자의 비밀번호 만료일, 유예 기간 등을 설정하여 보안을 강화합니다.

### **계정 만료일 설정 (`-E`, `-e`)**
* 사용자 생성 시: `sudo useradd -e YYYY-MM-DD LOGIN`
* 기존 사용자 변경: `sudo chage -E YYYY-MM-DD LOGIN`

```bash
$sudo chage -E 2026-05-01 user1$ sudo chage -l user1
# ...
# Account expires : May 01, 2026  <-- 계정 자체가 만료되는 날짜
```

### **비밀번호 유효/유예 기간 설정 (`-M`, `-I`)**
* `-M` : 비밀번호 최대 사용 가능 일수 (보통 30일, 60일, 90일 설정)
* `-I` (대문자 i) : 비밀번호 만료 후 변경을 허용해주는 유예 기간(Inactive 일수)

```bash
$sudo chage -M 2 user3   # 비밀번호 유효 기간을 2일로 설정$ sudo chage -I 5 user3   # 만료 후 5일간의 유예 기간 설정

$ sudo chage -l user3
Last password change                                    : Mar 19, 2026  # 비번 변경 날짜
Password expires                                        : Mar 21, 2026  # Last change + Maximum(2일)
Password inactive                                       : Mar 26, 2026  # Password expires + 유예(5일)
Maximum number of days between password change          : 2
```
