#### **💡 Inode와 Quota(쿼터)의 필요성**
HDD 파티션은 용량과 개수가 정해져 있습니다. 기본값이 모든 사용자가 제한이 없기 때문에 악의적인 일반 사용자가 파일의 개수를 채우는 공격을 아래처럼 시도할 수 있습니다. 

이것을 막아주는 대응 방안으로 사용자마다 용량과 개수를 제한하는 **Quota(쿼터)**를 설정해야 합니다. 만약 파일이 HDD 생성 개수(Inode)를 모두 채우면 더 이상 파일이 생성되지 않습니다. 단독으로 혼자 사용하는 서버는 상관이 없지만 여러 사람들이 공용으로 사용하는 서버는 관리자가 반드시 Quota를 사용자마다 설정해야 이를 막을 수 있습니다.

```bash
$ vi create_file.sh
```

```bash
#!/bin/sh

i=1
while(( 1 ))
do
    # printf "$i\n"
    touch ${i}.txt
    i=$((i+1))
done
```

```bash
$ ./create_file.sh
```
*(10분 후 `Ctrl + C` 로 실행을 종료합니다.)*

### **6. `diff` : 차이 비교**
* `difference`의 약자로 파일을 비교할 때 사용합니다.
* 서로 같으면 아무것도 나오지 않고, 다르면 차이점을 나타내는 문자가 출력됩니다.

```bash
$ diff file1.txt file2.txt
# <-- 파일의 내용이 같으므로 출력되지 않는다.

$ cat file1.txt
12345
$ cat file3.txt
1234545
```

#### **출력 해석 (file1.txt vs file3.txt)**
파일의 내용이 다르므로 결과가 출력됩니다.
* `1c1`: 첫 번째 파일(`file1.txt`)의 1번째 줄과 두 번째 파일(`file3.txt`)의 1번째 줄이 변경(`c`, change)되었다는 의미.
* `< 12345`: 첫 번째 파일(`file1.txt`)의 내용
* `---`: 두 파일의 내용을 구분하는 구분선
* `> 1234545`: 두 번째 파일(`file3.txt`)의 내용

**기호의 의미 요약:**
* `<` : 첫 번째 파일의 내용
* `>` : 두 번째 파일의 내용
* `c` : change, 변경
* `a` : add, 추가
* `d` : delete, 삭제

```bash
$ diff file1.txt file3.txt
1c1
< 12345
---
> 1234545
```

#### **추가 비교 실습**

```bash
$ cat << EOF > file1.txt
hello
12345
67890
EOF

$ cat << EOF > file2.txt
HELLO

67890
12345
EOF

$ cat file1.txt
hello
12345
67890

$ cat file2.txt
HELLO

67890
12345
```

#### **출력 해석 (복합적인 차이)**
* `1,2c1,2`: 첫 번째 파일의 1~2번째 줄이 두 번째 파일의 1~2번째 줄로 변경(`c`)됨.
* `< hello`, `< 12345`: 첫 번째 파일의 변경 전 내용.
* `> HELLO`, `> `: 두 번째 파일의 변경 후 내용 (`HELLO`와 빈 줄).
* `3a4`: 첫 번째 파일의 3번째 줄 다음에 두 번째 파일의 4번째 줄이 추가(`a`)됨. 즉, `file2.txt`에는 `file1.txt`에 없는 줄이 하나 더 있음.
* `> 12345`: 두 번째 파일의 4번째 줄 내용.
* **종합 의미**: `file1.txt`의 1~2줄이 `HELLO`와 빈 줄로 바뀌었고, `12345`는 `file2.txt`의 4번째 줄로 내려갔다는 의미입니다.

```bash
$ diff file1.txt file2.txt
1,2c1,2
< hello
< 12345
---
> HELLO
>
3a4
> 12345
```
