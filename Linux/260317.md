## 실무 서버 운영체제 및 리눅스 역사

### 1. 실무에서 사용하는 서버 OS
* **UNIX 서버**
  * 상용: HP-UX (HP), AIX (IBM)
  * 무료: Solaris, Open Solaris
* **Linux 서버**
  * 상용: RHEL (RedHat Enterprise Linux), Ubuntu (상용 지원)
  * 무료: Rocky Linux, Ubuntu (무료 버전)
  * *참고*: 카카오뱅크는 초기에 MySQL DBMS 기반으로 시작했습니다.

### 2. 주요 개념 및 라이선스 (참고)
* **GNU 선언문**: 자유 소프트웨어의 철학을 담은 선언문
* **FSF (자유 소프트웨어 재단)**: 자유 소프트웨어 운동을 지원하는 단체
* **GPL 라이선스**: GNU 일반 공중 사용 허가서 (자유 소프트웨어 라이선스)

### 3. RedHat과 리눅스 배포판의 역사

**📍 RedHat과 Fedora의 탄생**
* 90년대 중반 이후 RedHat은 공개 버전(6.2 ~ 9.x)을 발표하며 대중화되었습니다.
* 2001~2002년경 상용 버전인 **RHEL**을 출시하며, 기존 대중용 공개 버전의 업데이트 중단을 선언했습니다.
* 커뮤니티의 큰 반발이 일자, RedHat은 공개 버전을 커뮤니티에 이관하고 이를 지원하기로 결정했는데 이것이 바로 **Fedora 프로젝트**입니다.

**📍 CentOS의 변화와 Rocky Linux의 부상**
* 실무에서는 RHEL의 강력한 기능을 무료로 쓸 수 있는 **CentOS**를 주로 사용해 왔습니다.
* 2014년 RedHat이 CentOS 커뮤니티를 인수하였고, 이후 IBM과 합병하면서 CentOS를 테스트 버전 격인 **CentOS Stream**으로 변경했습니다. (CentOS 8 개발 조기 종료)
* **CentOS 7**은 2024년 6월 30일부로 EOL(End of Life)되어 보안 업데이트가 중단되었습니다. (현재 Suse Linux 진영에서 유료로 연장 지원 중)

**📍 배포판 생성 흐름의 변화**
* **과거**: Fedora Linux -> RHEL -> CentOS
* **현재**: Fedora Linux -> CentOS Stream -> RHEL -> **Rocky Linux**

### 4. 주요 리눅스 커널 및 보안 기술

**📍 SELinux (Security-Enhanced Linux)**
* **개발 배경**: 미국 국가안보국(NSA)이 리눅스 시스템 보안 강화와 필수 접근 제어(MAC, Mandatory Access Control) 구현을 위해 개발했습니다.
* **협력 및 통합**: RedHat과 협력하여 리눅스 커널에 통합되었습니다.
* **목적**: 파일, 프로세스 등 시스템 리소스 접근 권한을 엄격하게 제한하여 보안을 강화합니다.
* **적용**: RHEL 및 파생 배포판(CentOS, Rocky Linux 등)에서 기본 보안 기능으로 널리 사용됩니다.

**📍 GNU Hurd (GNU 허드)**
* **개요**: FSF의 GNU 프로젝트에서 개발 중인 유닉스 호환 운영체제용 커널입니다.
* **특징**: 단일 커널인 리눅스와 달리, 마이크로커널(Mach)을 기반으로 사용자 공간에서 서버들이 상호작용하는 구조를 가집니다.
* **현황**: 30년 이상 개발되었으나 안정성 및 성능 문제로 상용화 수준은 아니며 주로 연구/개발용으로 쓰입니다. (예: 데비안 GNU/Hurd)
* **리눅스와의 관계**: 원래 GNU 프로젝트는 Hurd 커널을 기획했으나 기술적 지연으로 인해 리눅스 커널과 결합된 **GNU/Linux** 시스템이 널리 보급되었습니다.
