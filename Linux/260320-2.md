### **hostname : 호스트명 확인**
  . FQDN (Fully Qualified Domain Name)으로 전체 도메인 이름을 출력한다.
    - 호스트 이름부터 도메인 이름까지 전체를 다 적은 이름을 의미한다.
    - www.naver.com, www.daum.net, cafe.naver.com
    - localhost.localdomain 은 기본값이고
       네트워크 장비에서 Switch, Router 기본 이름으로 보이는 것과 동일하다.

```bash
    $ hostname
    localhost.localdomain

    $ strace hostname
```

### **hostnamectl : 호스트명 설정/확인**
  . 호스트명을 확인하거나 변경한다.
    - localhost.localdomain 이면 /etc/hostname 에 저장되지 않는다.
    - FQDN을 설정하면 /etc/hostname에 저장된다.

```bash
    $ hostnamectl --help
    $ sudo hostnamectl hostname command.linuxmaster.net
    $ cat /etc/hostname
    command.linuxmaster.net
    $ hostname
    command.linuxmaster.net
    $ exit 
      ssh linuxadmin@192.168.100.3
    linuxadmin@192.168.100.3's password:
    [linuxadmin@command ~]$

    $ sudo vi /etc/hosts
    127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4
    ::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
    192.168.100.3 command.linuxmaster.net command
```

### **압축/아카이브**
  . 파일 압축은 gzip, bzip2, xz, zip 이 있다.
    - 그중에서도 gzip, bzip2, xz를 많이 사용한다.

### **gzip : gzip 압축**
  . 압축을 하면 원본 파일을 압축하고 원본파일을 삭제한다.
    - gzip으로 압축하면 파일명.gz 으로 생성된다.
    - 압축을 해제하려면 -d 옵션을 사용한다.
    Usage: gzip [OPTION]... [FILE]...
    -d, --decompress  decompress

```bash
        $ cp /usr/bin/{ls,mv} .
      $ gzip ls mv
    $ ls
    ls.gz  mv.gz
    $ gzip -d ls.gz mv.gz
```

### **gunzip : gzip 해제**
  . gzip으로 압축된 파일을 압축을 해제한다.
    - .gz 은 gzip 확장자이다. 
    - /usr/bin/gunzip 으로 파일이 존재하고 셸스크립트 파일로 되어있다.
    - 실제 실행은 gzip -d 옵션을 사용한다.

```bash
    $ file $(which gunzip)
    /usr/bin/gunzip: a /usr/bin/sh script, ASCII text executable
    $ tail -n 1 /usr/bin/gunzip
    exec gzip -d "$@"
```

  옵션 설명
      . 원본 파일을 유지하고 싶은 경우 -c 옵션을 사용한다.
        - -c, --stdout  write on standard output, keep original files unchanged

```bash
    $ cat /etc/hosts > hosts
    $ gzip -c hosts > hosts.gz
    $ rm -f hosts
    $ gzip -d hosts.gz   
    $ cat hosts
```

  실행파일은 실행권한 x가 빠져있기 때문에 chmod로 실행권한 x를 설정한다.

```bash
    $ gzip -c ls > ls.gz
    $ ls 
    $ rm -f ls
    $ gunzip ls.gz
    $ chmod 755 ls
```

### **bzip2 : bzip2 압축, bunzip2 : bzip2 해제**
  . gzip 다음에 많이 사용하는 압축 프로그램이다.
    - .bz2 은 bzip2 확장자이다. 
    - Rocky Linux9에서 패키지가 없기 때문에 dnf 로 설치한다.
    - gzip <--> gunzip bzip2 <--> bunzip2
    - /usr/bin/bunzip2 -> /usr/bin/bzip2 의 심볼릭 링크 파일이다.
      . 옵션
    - -d --decompress  force decompression
    - -c --stdout  output to standard out 
    - --fast  alias for -1
    - --best  alias for -9

```bash
        $ sudo dnf -y install bzip2 > /dev/null 2> /dev/null
    $ bzip2 *
    $ bzip2 -d ls.bz2
    $ bunzip2 mv.bz2
```

  원본 파일을 남기고 싶다면 -c 옵션을 사용한다.
      . 

```bash
    $ bzip2 -c hosts > hosts.bz2
```

### **xz : xz 압축, unxz : xz 해제**
  . gzip, bzip2 보다 압축률이 더 좋다.
    . 옵션
    - -d, --decompress  force decompression
    - /usr/bin/unxz -> /usr/bin/xz 의 심볼릭 링크 파일이다.

```bash
    $ rm -f *
    $ cp /bin/ls .
    $ xz ls
    $ file ls.xz
    ls.xz: XZ compressed data
    $ xz -d ls.xz        
    $ xz ls
    $ unxz ls.xz
```

### **zip : zip 압축, unzip : zip 해제**
  . 윈도우에서 많이 사용하는 압축 프로그램으로 리눅스에서도 동일하게 사용할 수 있다.
    - Rocky Linux9에서 패키지가 없기 때문에 dnf 로 설치한다.        
    - 압축, 해제를 할 때 다른 압축 명령어와 다르게 원본 파일을 삭제하지 않는다.

```bash
    $ sudo dnf -y install zip > /dev/null 2>&1  # > /dev/null 2> /dev/null 와 동일
    $ zip --help
    $ zip ls.zip ls

    $ unzip -l ls.zip
    $ zipinfo -l ls.zip        
    $ rm -fv ls
    $ unzip ls.zip
```

### **zcat : 압축파일 내용 보기**
  . zcat은 셸스크립트 파일로 실제 압축을 해제하면서 화면으로 출력하는 명령어이다.
    - gzip -cd 파일명.gz 
    - man ls 로 도움말을 확인할 때 도움말 파일이 gzip으로 압축되어 있는데 gzip -d 로 압축을 풀로 보여주는 것이다.

```bash
    $ cp /etc/crontab .  # cp /etc/crontab crontab 과 동일
    $ cp /etc/crontab crontab.txt
    $ gzip *

    $ cat crontab.gz   <-- 깨진다.
    $ zcat crontab.gz  <-- 정상 출력
    $ file $(which zcat)
    /usr/bin/zcat: a /usr/bin/sh script, ASCII text executable
    $ tail -n 1 /usr/bin/zcat
    exec gzip -cd "$@"

    $ cp /usr/share/man/man1/ls.1.gz .
    $ gzip -d ls.1.gz
    $ cat ls.1
```

### **tar : 묶기/풀기**
  . 파일을 묶고 푸는 명령어로 기본적으로 압축을 하지 않는다.
    - 압축, 압축해제는 하지 않고 묶고, 푸는 역할만 한다.
      . 옵션
    -c, --create               create a new archive
    -t, --list                 list the contents of an archive
    -x, --extract, --get       extract files from an archive
    -v, --verbose              verbosely list files processed
    -z, --gzip, --gunzip, --ungzip   filter the archive through gzip
    -j, --bzip2                filter the archive through bzip2
    -J, --xz                   filter the archive through xz

```bash
    $ rm -f *
    $ sudo dnf -y install tar 2> /dev/null >&2

    c로 묶고 t로 보고 x로 푼다.
    $ tar -cvf myfile.tar 1.txt 2.txt 3.txt
    $ tar -tf myfile.tar 1.txt 2.txt 3.txt
    $ rm -fv [1-3].txt
    $ tar xf myfile.tar        

    $ gzip myfile.tar  # myfile.tar.gz
    $ gzip -d myfile.tar.gz        

    $ bzip2 myfile.tar  # myfile.tar.bz2
    $ bzip2 -d myfile.tar.bz2

    $ xz myfile.tar  # myfile.tar.xz 
    $ rm -f myfile.tar.xz        

    $ tar czf myfile.tar.gz  [123].txt
    $ tar cjf myfile.tar.bz2 [123].txt
    $ tar cJf myfile.tar.xz  [123].txt        

    $ rm -f *.txt
    $ tar xzf myfile.tar.gz
    $ ll        

    $ rm -f
    $ rm -f *.txt
    $ tar xjf myfile.tar.bz2
    $ ll        

    $ rm -f *.txt
    $ tar xJf myfile.tar.xz
    $ ll
```
